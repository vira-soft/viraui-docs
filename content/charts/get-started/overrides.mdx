Default chart marks pick up Vira theme tokens. Pass stroke and tick colors when a plot needs a different highlight — any valid CSS color or `var(--*)` works.

## Common examples

### Series and chrome

Acid series stroke with magenta tick strokes on the axes.

<Example preview={<ChartsOverridesDemo />}>

```tsx
import {
  AxisBottom,
  AxisLeft,
  GridRows,
  Group,
  LinePath,
  scaleLinear,
} from '@viraui/charts';

const xScale = scaleLinear({ domain: [0, data.length - 1], range: [0, innerWidth] });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0] });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    <LinePath
      data={data}
      x={(d) => xScale(d.x) ?? 0}
      y={(d) => yScale(d.y) ?? 0}
      stroke="var(--highlight-acid)"
    />
    <AxisLeft scale={yScale} numTicks={3} tickStroke="var(--highlight-magenta)" />
    <AxisBottom top={innerHeight} scale={xScale} numTicks={3} tickStroke="var(--highlight-magenta)" />
  </Group>
</svg>
```

</Example>
