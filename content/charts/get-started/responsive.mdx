Fixed-pixel Storybook widths teach the marks. In an app the plot usually fills a card or panel. `@viraui/charts` re-exports visx sizing helpers so the SVG tracks the host.

Each preview below uses the same horizontally **resizable** sandbox as [fluid typography](/foundation/typography) — drag the iframe edge to watch `ParentSize` / `useParentSize` / `ScaleSVG` reflow.

## Common examples

### useParentSize

Measure a ref and pass `width` / `height` into marks.

<Example preview={<ChartsResponsiveUseParentSizeDemo />}>

```tsx
import {
  AxisBottom,
  GridRows,
  Group,
  LinePath,
  useParentSize,
  scaleLinear,
} from '@viraui/charts';

function MeasuredChart() {
  const { parentRef, width, height } = useParentSize({ debounceTime: 0 });
  const innerWidth = width - margin.left - margin.right;
  const innerHeight = height - margin.top - margin.bottom;
  const xScale = scaleLinear({ domain: [0, lineData.length - 1], range: [0, innerWidth] });
  const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0] });

  return (
    <div ref={parentRef} style={{ width: '100%', height: 280 }}>
      <svg width={width} height={height}>
        <Group left={margin.left} top={margin.top}>
          <GridRows scale={yScale} width={innerWidth} numTicks={3} />
          <LinePath data={lineData} x={(d) => xScale(d.x) ?? 0} y={(d) => yScale(d.y) ?? 0} />
          <AxisBottom top={innerHeight} scale={xScale} numTicks={3} hideAxisLine hideTicks />
        </Group>
      </svg>
    </div>
  );
}
```

</Example>

### ParentSize

Same measurement with a render prop instead of a ref hook.

<Example preview={<ChartsResponsiveParentSizeDemo />}>

```tsx
import {
  AxisBottom,
  GridRows,
  Group,
  LinePath,
  ParentSize,
  scaleLinear,
} from '@viraui/charts';

<div style={{ width: '100%', height: 280 }}>
  <ParentSize debounceTime={0}>
    {({ width, height }) => {
      const innerWidth = width - margin.left - margin.right;
      const innerHeight = height - margin.top - margin.bottom;
      const xScale = scaleLinear({ domain: [0, lineData.length - 1], range: [0, innerWidth] });
      const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0] });
      return (
        <svg width={width} height={height}>
          <Group left={margin.left} top={margin.top}>
            <GridRows scale={yScale} width={innerWidth} numTicks={3} />
            <LinePath data={lineData} x={(d) => xScale(d.x) ?? 0} y={(d) => yScale(d.y) ?? 0} />
            <AxisBottom top={innerHeight} scale={xScale} numTicks={3} hideAxisLine hideTicks />
          </Group>
        </svg>
      );
    }}
  </ParentSize>
</div>
```

</Example>

### useScreenSize

Size from the viewport when the card is not the constraint.

<Example preview={<ChartsResponsiveUseScreenSizeDemo />}>

```tsx
import { useScreenSize } from '@viraui/charts';

const { width: screenWidth, height: screenHeight } = useScreenSize({ debounceTime: 0 });
const width = Math.max(0, (screenWidth || 640) - 48);
const height = Math.min(Math.max((screenHeight || 720) * 0.4, 200), 420);

<svg width={width} height={height} role="img" aria-label="useScreenSize line chart">
  <LineChartMarks width={width} height={height} />
</svg>
```

</Example>

### ScaleSVG

When the composition is authored at a fixed viewBox and should scale into the host, wrap marks in `ScaleSVG` — do not nest another `<svg>` inside.

<Example preview={<ChartsResponsiveScaleSvgDemo />}>

```tsx
import { ScaleSVG } from '@viraui/charts';

<div style={{ width: '100%', height: 'auto' }} role="img" aria-label="ScaleSVG line chart">
  <ScaleSVG width={400} height={240}>
    <LineChartMarks width={400} height={240} />
  </ScaleSVG>
</div>
```

</Example>

### Fluid bar

Rebuild band and linear scales from the measured box.

<Example preview={<ChartsResponsiveBarDemo />}>

```tsx
import {
  AxisBottom,
  BarRounded,
  GridRows,
  Group,
  ParentSize,
  scaleBand,
  scaleLinear,
} from '@viraui/charts';

<ParentSize debounceTime={0}>
  {({ width, height }) => {
    const innerWidth = width - margin.left - margin.right;
    const innerHeight = height - margin.top - margin.bottom;
    const xScale = scaleBand({ domain: months, range: [0, innerWidth], padding: 0.3 });
    const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });
    return (
      <svg width={width} height={height}>
        <Group left={margin.left} top={margin.top}>
          <GridRows scale={yScale} width={innerWidth} numTicks={3} />
          {desktopData.map((d) => {
            const barY = yScale(d.value) ?? 0;
            return (
              <BarRounded
                key={d.month}
                x={xScale(d.month) ?? 0}
                y={barY}
                width={xScale.bandwidth()}
                height={Math.max(0, innerHeight - barY)}
                all={false}
                top
              />
            );
          })}
          <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
        </Group>
      </svg>
    );
  }}
</ParentSize>
```

</Example>

### Fluid area

Same host pattern with `AreaClosed` and point scales.

<Example preview={<ChartsResponsiveAreaDemo />}>

```tsx
import {
  AreaClosed,
  AxisBottom,
  GridRows,
  Group,
  ParentSize,
  curveMonotoneX,
  scaleLinear,
  scalePoint,
} from '@viraui/charts';

<ParentSize debounceTime={0}>
  {({ width, height }) => {
    const innerWidth = width - margin.left - margin.right;
    const innerHeight = height - margin.top - margin.bottom;
    const xScale = scalePoint({ domain: months, range: [0, innerWidth] });
    const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });
    return (
      <svg width={width} height={height}>
        <Group left={margin.left} top={margin.top}>
          <GridRows scale={yScale} width={innerWidth} numTicks={3} />
          <AreaClosed
            data={desktopData}
            x={(d) => xScale(d.month) ?? 0}
            y={(d) => yScale(d.value)}
            yScale={yScale}
            curve={curveMonotoneX}
          />
          <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
        </Group>
      </svg>
    );
  }}
</ParentSize>
```

</Example>

### Fluid pie

Center `Pie` using `min(width, height)` for radius.

<Example preview={<ChartsResponsivePieDemo />}>

```tsx
import { Group, ParentSize, Pie, scaleOrdinal } from '@viraui/charts';

<ParentSize debounceTime={0} initialSize={{ width: 640, height: 320 }}>
  {({ width, height }) => {
    const radius = Math.max(0, Math.min(width, height) / 2 - 12);
    return (
      <svg width={width} height={height} role="img" aria-label="Responsive pie chart">
        <Group top={height / 2} left={width / 2}>

            {({ arcs, path }) =>

          </Pie>

  }}
</ParentSize>
```

</Example>

### Fluid radar

Polar scales from the smaller of width and height.

<Example preview={<ChartsResponsiveRadarDemo />}>

```tsx
import { Group, LineRadial, ParentSize, scaleLinear } from '@viraui/charts';

<ParentSize debounceTime={0} initialSize={{ width: 640, height: 360 }}>
  {({ width, height }) => {
    const radius = Math.max(0, Math.min(width, height) / 2 - 36);
    const radialScale = scaleLinear({ range: [0, Math.PI * 2], domain: [360, 0] });
    const valueScale = scaleLinear({ range: [0, radius], domain: [0, radarMax] });
    return (
      <svg width={width} height={height} role="img" aria-label="Responsive radar chart">
        <Group top={height / 2} left={width / 2}>
          <LineRadial
            data={monthDeviceData}
            angle={(_, i) => radialScale(i * (360 / monthDeviceData.length)) ?? 0}
            radius={(d) => valueScale(d.desktop) ?? 0}
            fill="oklab(from var(--highlight-cyan) l a b / 28%)"
            stroke="var(--highlight-cyan)"
            strokeWidth={2}
          />
        </Group>
      </svg>
    );
  }}
</ParentSize>
```

</Example>

### Mobile scrub

For dense day series on a narrow viewport, sticky Y + horizontal scroll + a header that reads the scrubbed point beats a floating tooltip. The Line family owns the marks; this page owns the responsive shell.

<Example preview={<ChartsResponsiveMobileScrubDemo />}>

```tsx
import {
  AxisBottom,
  AxisRight,
  Circle,
  GridColumns,
  GridRows,
  Group,
  LinePath,
  curveMonotoneX,
  scaleLinear,
  scalePoint,
} from '@viraui/charts';

const plotWidth = Math.max(days.length * 12, hostWidth);
const xScale = scalePoint({ domain: days.map((d) => d.key), range: [0, plotWidth] });
const yScale = scaleLinear({ domain: yDomain, range: [innerHeight, 0] });

<div style={{ display: 'flex' }}>
  <div style={{ overflowX: 'auto', flex: 1 }} tabIndex={0}>
    <svg width={plotWidth} height={height}>
      <Group top={margin.top}>
        <GridRows scale={yScale} width={plotWidth} tickValues={yTicks} />
        <GridColumns scale={xScale} height={innerHeight} tickValues={xTicks} strokeDasharray="3 5" />
        <LinePath
          data={days}
          x={(d) => xScale(d.key) ?? 0}
          y={(d) => yScale(d.bpm)}
          curve={curveMonotoneX}
        />
        {days.map((d) => (
          <Circle key={d.key} cx={xScale(d.key) ?? 0} cy={yScale(d.bpm)} r={3.5} />
        ))}
        <AxisBottom top={innerHeight} scale={xScale} tickValues={xTicks} hideAxisLine hideTicks />
      </Group>
    </svg>
  </div>
  <svg width={yAxisWidth} height={height} aria-hidden>
    <Group top={margin.top}>
      <AxisRight scale={yScale} tickValues={yTicks} hideAxisLine hideTicks />
    </Group>
  </svg>
</div>
```

</Example>
