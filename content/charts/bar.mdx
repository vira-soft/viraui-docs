title: Bar
icon: ChartBar
description: Discrete columns — vertical, horizontal, grouped, stacked, labeled, mixed, and negative.
---

Bar charts compare magnitudes across categories. Compose `Bar` / `BarRounded` / `BarStack` with band scales from `@viraui/charts`.

Reach for Bar when categories are discrete. Prefer [Line](/charts/line) / [Area](/charts/area) for continuous trends, and [Pie](/charts/pie) for part-to-whole without a shared baseline.

---

## When to use

- Monthly or named category magnitudes
- Grouped or stacked channel comparisons
- Values that cross zero

## When not to use

- Continuous time trends with many points → [Line](/charts/line)
- Part-to-whole without categories on an axis → [Pie](/charts/pie)

---

## Common examples

### Simple

Rounded columns with a month axis and row grid.

<Example preview={<ChartsBarSimpleDemo />}>

```tsx
import { AxisBottom, BarRounded, GridRows, Group, scaleBand, scaleLinear } from '@viraui/charts';

const xScale = scaleBand({ domain: months, range: [0, innerWidth], padding: 0.3 });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    {desktopData.map((d) => {
      const barY = yScale(d.value) ?? 0;
      return (
        <BarRounded
          key={d.month}
          x={xScale(d.month) ?? 0}
          y={barY}
          width={xScale.bandwidth()}
          height={Math.max(0, innerHeight - barY)}
          fill="var(--highlight-cyan)"
        />
      );
    })}
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Dense

Day-level columns with width-aware X ticks (no Y axis).

<Example preview={<ChartsBarDenseDemo />}>

```tsx
import { AxisBottom, Bar, GridRows, Group, ParentSize, scaleBand, scaleLinear } from '@viraui/charts';

<ParentSize>
  {({ width, height }) => {
    const innerWidth = width - margin.left - margin.right;
    const innerHeight = height - margin.top - margin.bottom;
    const domain = days.map((d) => d.key);
    const xScale = scaleBand({ domain, range: [0, innerWidth], padding: 0.12 });
    const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });
    const tickValues = thinDomainTicks(domain, innerWidth);

    return (
      <svg width={width} height={height}>
        <Group left={margin.left} top={margin.top}>
          <GridRows scale={yScale} width={innerWidth} numTicks={3} />
          {days.map((d) => {
            const barY = yScale(d.value) ?? 0;
            return (
              <Bar
                key={d.key}
                x={xScale(d.key) ?? 0}
                y={barY}
                width={xScale.bandwidth()}
                height={Math.max(0, innerHeight - barY)}
                fill="var(--highlight-blue)"
              />
            );
          })}
          <AxisBottom
            top={innerHeight}
            scale={xScale}
            tickValues={tickValues}
            tickFormat={(value) => shortLabel(value)}
            hideAxisLine
            hideTicks
          />
        </Group>
      </svg>
    );
  }}
</ParentSize>
```

</Example>

### Multiple

Grouped desktop / mobile columns.

<Example preview={<ChartsBarMultipleDemo />}>

```tsx
import { AxisBottom, BarRounded, GridRows, Group, scaleBand, scaleLinear } from '@viraui/charts';

const xScale = scaleBand({ domain: months, range: [0, innerWidth], padding: 0.25 });
const xGroup = scaleBand({
  domain: ['desktop', 'mobile'],
  range: [0, xScale.bandwidth()],
  padding: 0.15,
});
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    {multiData.map((d) => {
      const groupX = xScale(d.month) ?? 0;
      return (
        <Group key={d.month}>
          <BarRounded
            x={groupX + (xGroup('desktop') ?? 0)}
            y={yScale(d.desktop) ?? 0}
            width={xGroup.bandwidth()}
            height={Math.max(0, innerHeight - (yScale(d.desktop) ?? 0))}
            all={false}
            top
            fill="var(--highlight-cyan)"
          />
          <BarRounded
            x={groupX + (xGroup('mobile') ?? 0)}
            y={yScale(d.mobile) ?? 0}
            width={xGroup.bandwidth()}
            height={Math.max(0, innerHeight - (yScale(d.mobile) ?? 0))}
            all={false}
            top
            fill="var(--highlight-indigo)"
          />
        </Group>
      );
    })}
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Stacked

Stacked channel columns.

<Example preview={<ChartsBarStackedDemo />}>

```tsx
import { AxisBottom, Bar, BarRounded, GridRows, Group, scaleBand, scaleLinear } from '@viraui/charts';

const xScale = scaleBand({ domain: months, range: [0, innerWidth], padding: 0.3 });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    {multiData.map((d) => {
      const x = xScale(d.month) ?? 0;
      const desktopY = yScale(d.desktop) ?? 0;
      const totalY = yScale(d.desktop + d.mobile) ?? 0;
      return (
        <Group key={d.month}>
          <Bar
            x={x}
            y={desktopY}
            width={xScale.bandwidth()}
            height={Math.max(0, innerHeight - desktopY)}
            fill="var(--highlight-cyan)"
          />
          <BarRounded
            x={x}
            y={totalY}
            width={xScale.bandwidth()}
            height={Math.max(0, desktopY - totalY - 3)}
            all={false}
            top
            fill="var(--highlight-indigo)"
          />
        </Group>
      );
    })}
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Mixed

One active category highlighted.

<Example preview={<ChartsBarMixedDemo />}>

```tsx
import { AxisBottom, BarRounded, GridRows, Group, scaleBand, scaleLinear, scaleOrdinal } from '@viraui/charts';

const names = browserData.map((d) => d.name);
const xScale = scaleBand({ domain: names, range: [0, innerWidth], padding: 0.3 });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });
const colorScale = scaleOrdinal({ domain: names, range: browserColors });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    {browserData.map((d) => {
      const barY = yScale(d.value) ?? 0;
      const fill = colorScale(d.name);
      const isActive = d.name === active;
      return (
        <Group key={d.name}>
          <BarRounded
            x={xScale(d.name) ?? 0}
            y={barY}
            width={xScale.bandwidth()}
            height={Math.max(0, innerHeight - barY)}
            fill={fill}
          />
          {isActive ? (
            <BarRounded
              x={xScale(d.name) ?? 0}
              y={barY}
              width={xScale.bandwidth()}
              height={Math.max(0, innerHeight - barY)}
              fill="transparent"
              stroke={fill}
              strokeWidth={3}
              strokeDasharray="4 4"
            />
          ) : null}
        </Group>
      );
    })}
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Negative

Columns that cross zero.

<Example preview={<ChartsBarNegativeDemo />}>

```tsx
import { Bar, GridRows, Group, Text, scaleBand, scaleLinear } from '@viraui/charts';

const xScale = scaleBand({ domain: months, range: [0, innerWidth], padding: 0.35 });
const yScale = scaleLinear({ domain: [yMin, yMax], range: [innerHeight, 0], nice: true });
const zeroY = yScale(0) ?? 0;

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    <Bar x={0} y={zeroY} width={innerWidth} height={1} fill="var(--global-contrast)" />
    {signedData.map((d) => {
      const valueY = yScale(d.value) ?? 0;
      const positive = d.value >= 0;
      const color = positive ? 'var(--highlight-cyan)' : 'var(--highlight-indigo)';
      return (
        <Group key={d.month}>
          <Bar
            x={xScale(d.month) ?? 0}
            y={positive ? valueY : zeroY}
            width={xScale.bandwidth()}
            height={Math.abs(valueY - zeroY)}
            fill={color}
          />
          <Text
            x={(xScale(d.month) ?? 0) + xScale.bandwidth() / 2}
            y={positive ? valueY - 8 : valueY + 8}
            textAnchor="middle"
            verticalAnchor={positive ? 'end' : 'start'}
            fill={color}
          >
            {d.month}
          </Text>
        </Group>
      );
    })}
  </Group>
</svg>
```

</Example>
