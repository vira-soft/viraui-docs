Area charts fill under a path so magnitude reads as volume. Compose `AreaClosed` / `AreaStack` with the same scale and axis helpers as Line.

Reach for Area when fill carries the story. Prefer [Line](/charts/line) for thin multi-series trends without fill, and [Bar](/charts/bar) for discrete columns.

---

## When to use

- Single-series volume over time
- Stacked or expanded stacks that show channel mix

## When not to use

- Many overlapping series without stacking → [Line](/charts/line)
- Category comparison without a continuous domain → [Bar](/charts/bar)

---

## Common examples

### Natural

Monotone fill under the visitors series.

<Example preview={<ChartsAreaNaturalDemo />}>

```tsx
import {
  AreaClosed,
  AxisBottom,
  GridRows,
  Group,
  curveMonotoneX,
  scaleLinear,
  scalePoint,
} from '@viraui/charts';

const xScale = scalePoint({ domain: months, range: [0, innerWidth] });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    <AreaClosed
      data={data}
      x={(d) => xScale(d.month) ?? 0}
      y={(d) => yScale(d.value)}
      yScale={yScale}
      curve={curveMonotoneX}
    />
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Stacked

Absolute stack of desktop, mobile, and other.

<Example preview={<ChartsAreaStackedDemo />}>

```tsx
import {
  AreaStack,
  AxisBottom,
  GridRows,
  Group,
  curveMonotoneX,
  scaleLinear,
  scaleOrdinal,
  scalePoint,
} from '@viraui/charts';

const keys = ['desktop', 'mobile', 'other'];
const xScale = scalePoint({ domain: months, range: [0, innerWidth] });
const yScale = scaleLinear({ domain: [0, yMax], range: [innerHeight, 0], nice: true });
const colorScale = scaleOrdinal({ domain: keys, range: stackColors });

<svg width={width} height={height}>
  <Group left={margin.left} top={margin.top}>
    <GridRows scale={yScale} width={innerWidth} numTicks={3} />
    <AreaStack
      data={stackData}
      keys={keys}
      x={(d) => xScale(d.data.month) ?? 0}
      y0={(d) => yScale(d[0]) ?? 0}
      y1={(d) => yScale(d[1]) ?? 0}
      color={(key) => colorScale(String(key))}
      curve={curveMonotoneX}
    >
      {({ stacks, path }) =>
        stacks.map((stack) => (
          <path key={stack.key} d={path(stack) ?? undefined} fill={colorScale(String(stack.key))} />
        ))
      }
    </AreaStack>
    <AxisBottom top={innerHeight} scale={xScale} hideAxisLine hideTicks />
  </Group>
</svg>
```

</Example>

### Dense

Day-level series in a fluid `ParentSize` host with width-aware X ticks.

<Example preview={<ChartsAreaDenseDemo />}>

```tsx
import {
  AreaClosed,
  AxisBottom,
  GridRows,
  Group,
  ParentSize,
  curveMonotoneX,
  scaleLinear,
  scalePoint,
} from '@viraui/charts';

<ParentSize>
  {({ width, height }) => {
    const plotWidth = width - margin.left - margin.right;
    const plotHeight = height - margin.top - margin.bottom;
    const domain = days.map((d) => d.key);
    const xScale = scalePoint({ domain, range: [0, plotWidth] });
    const yScale = scaleLinear({ domain: [0, yMax], range: [plotHeight, 0], nice: true });
    const tickValues = thinDomainTicks(domain, plotWidth);

    return (
      <svg width={width} height={height}>
        <Group left={margin.left} top={margin.top}>
          <GridRows scale={yScale} width={plotWidth} numTicks={3} />
          <AreaClosed
            data={days}
            x={(d) => xScale(d.key) ?? 0}
            y={(d) => yScale(d.mobile)}
            yScale={yScale}
            curve={curveMonotoneX}
          />
          <AreaClosed
            data={days}
            x={(d) => xScale(d.key) ?? 0}
            y={(d) => yScale(d.desktop)}
            yScale={yScale}
            curve={curveMonotoneX}
          />
          <AxisBottom
            top={plotHeight}
            scale={xScale}
            tickValues={tickValues}
            tickFormat={(value) => shortLabel(value)}
            hideAxisLine
            hideTicks
          />
        </Group>
      </svg>
    );
  }}
</ParentSize>
```

</Example>
