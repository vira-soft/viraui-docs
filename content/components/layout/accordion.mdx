## Base UI

<Cards>
  <Card
    title="Accordion"

    Upstream API and behavior for the Base UI primitive this control wraps.
  </Card>
</Cards>

`Accordion` wraps Base UI accordion primitives in a column [`Stack`](/components/layout/stack) — each `Accordion.Item` owns the trigger header and collapsible panel, so you pass a `trigger` label and panel children instead of composing public Header / Trigger / Panel parts. Root `value`, `defaultValue`, and `onValueChange` come from Base UI; set `multiple` when several sections can stay open — exclusive FAQs stay single-open by default. Items wrap [`Surface`](/components/layout/surface) by default — `color`, `border`, and `radius` forward to that host, and root `islands` toggles separated cards versus an attached block with corner radius only on the first and last rows. Keyboard and aria behavior stay upstream; you compose items, copy, and surrounding chrome in JSX.

## Common examples

### Exclusive open

One open panel at a time is the default disclosure pattern — useful for FAQs where each answer replaces the previous. Items keep Surface islands with gap between cards; nest the accordion under a titled panel when the group needs chrome.

<Example preview={<AccordionExclusiveDemo />}>

```tsx
import { Accordion, Button, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} overflow="hidden" radius="l">
  <Stack rowGap="l">
    <Stack hPadding="m" rowGap="l" vPadding="m">
      <Stack rowGap="xs">
        <Title />
        <Text size="s" tone="muted" />
      </Stack>
      <Accordion defaultValue={['tax-docs']}>
        <Accordion.Item border="all" color={2} trigger="When do payouts arrive?" value="arrival-timing">
          <Text tone="muted" />
        </Accordion.Item>
        <Accordion.Item border="all" color={2} trigger="What fees apply?" value="fees">
          <Text tone="muted" />
        </Accordion.Item>
        <Accordion.Item border="all" color={2} trigger="Tax documents" value="tax-docs">
          <Text tone="muted" />
        </Accordion.Item>
      </Accordion>
    </Stack>
    <Surface color={2} hPadding="l" vPadding="m">
      <Stack direction="row" hAlign="space-between" vAlign="center">
        <Button variant="secondary" />
        <Button />
      </Stack>
    </Surface>
  </Stack>
</Surface>
```

</Example>

### Multiple open

Pass `multiple` so several panels can stay expanded together — handy for settings groups where readers compare related answers. Seed open sections with `defaultValue` as an array of item values.

<Example preview={<AccordionMultipleDemo />}>

```tsx
import { Accordion, Text } from '@viraui/react';

<Accordion defaultValue={['notifications', 'exports']} multiple>
  <Accordion.Item border="all" color={1} trigger="Email notifications" value="notifications">
    <Text tone="muted" />
  </Accordion.Item>
  <Accordion.Item border="all" color={1} trigger="Security & sessions" value="security">
    <Text tone="muted" />
  </Accordion.Item>
  <Accordion.Item border="all" color={1} trigger="Data exports" value="exports">
    <Text tone="muted" />
  </Accordion.Item>
</Accordion>
```

</Example>

### Attached block

Set `islands={false}` when Surface items should read as one attached block — corner radius stays on the outer edges of the first and last rows instead of gapped islands. Leave `islands` on (the default) for separated cards.

<Example preview={<AccordionAttachedDemo />}>

```tsx
import { Accordion, Text } from '@viraui/react';

<Accordion defaultValue={['billing']} islands={false}>
  <Accordion.Item border="all" color={1} trigger="Billing contact" value="billing">
    <Text tone="muted" />
  </Accordion.Item>
  <Accordion.Item border="all" color={1} trigger="Locale & currency" value="locale">
    <Text tone="muted" />
  </Accordion.Item>
  <Accordion.Item border="all" color={1} trigger="Retention policy" value="retention">
    <Text tone="muted" />
  </Accordion.Item>
</Accordion>
```

</Example>
