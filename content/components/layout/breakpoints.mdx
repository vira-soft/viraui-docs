---
title: Breakpoints
description: BreakpointsProvider — named min-width match flags for viewport-conditional React trees.
---

`BreakpointsProvider` owns a map of breakpoint names to CSS lengths and subscribes to `window.matchMedia` for each `(min-width: …)` query. Descendants call [`useBreakpoints`](/get-started/utilities/use-breakpoints) to read which names currently match — pass one name for a boolean, or call with no argument for the full record. Mount the provider once in a client subtree (`'use client'` in Next.js); the hook throws outside that boundary. Passing `breakpoints` **replaces** the entire default map — it does not merge with the built-in names. Prefer CSS `@media` for layout-only shifts that keep the same markup; branch the React tree only when structure, mounted components, or Vira props must change. Defaults are hardcoded em lengths (not theme tokens) — the live name → length map lives in `@viraui/react/specs` under `breakpoints`, and style-only CSS should reuse those same lengths.

## Common examples

### Direction flip

A studio nav reads one named flag and flips Stack `direction` when that min-width matches — the provider must wrap every screen that calls the hook.

<Example preview={<BreakpointsDirectionDemo />}>

```tsx
'use client';

import { BreakpointsProvider, ButtonLink, Stack, Surface, Text, useBreakpoints } from '@viraui/react';

function StudioNav() {
  const isWide = useBreakpoints('small');

  return (
    <Surface border="all" color={1} hPadding="m" radius="l" vPadding="m">
      <Stack
        columnGap="xl"
        direction={isWide ? 'row' : 'column'}
        fullWidth
        hAlign={isWide ? 'space-between' : 'stretch'}
        render={<nav />}
        rowGap="s"
        vAlign={isWide ? 'center' : 'stretch'}
      >
        <Text />
        <Stack columnGap="xs" direction={isWide ? 'row' : 'column'} rowGap="xs">
          <ButtonLink href="#" size="s" variant="secondary" />
          <ButtonLink href="#" size="s" variant="secondary" />
          <ButtonLink href="#" size="s" variant="secondary" />
        </Stack>
      </Stack>
    </Surface>
  );
}

<BreakpointsProvider>
  <StudioNav />
</BreakpointsProvider>
```

</Example>

### Match record

Call `useBreakpoints()` with no argument when several names drive the same subtree — you get the full name → boolean record for the provider’s current map.

<Example preview={<BreakpointsRecordDemo />}>

```tsx
'use client';

import { BreakpointsProvider, Stack, Surface, Text, Title, useBreakpoints } from '@viraui/react';

function ViewportBoard() {
  const matches = useBreakpoints();

  return (
    <Surface border="all" color={1} hPadding="l" radius="l" vPadding="l">
      <Stack rowGap="m">
        <Title />
        <Text size="s" tone="muted" />
        <Stack columnGap="xs" direction="row" wrap>
          {Object.keys(matches).map((name) => (
            <Surface key={name} border="all" color={matches[name] ? 2 : 1} hPadding="s" radius="m" vPadding="xs">
              <Text size="s" />
            </Surface>
          ))}
        </Stack>
      </Stack>
    </Surface>
  );
}

<BreakpointsProvider>
  <ViewportBoard />
</BreakpointsProvider>
```

</Example>

### Custom map

The `breakpoints` prop installs a product map for that provider instance. Named hooks must use those keys only — sparse overrides do not keep default names like `small`.

<Example preview={<BreakpointsCustomMapDemo />}>

```tsx
'use client';

import { BreakpointsProvider, ButtonLink, Stack, Surface, Text, Title, useBreakpoints } from '@viraui/react';

const productBreakpoints = {
  compact: '20em',
  wide: '50em',
};

function ReleaseDesk() {
  const isWide = useBreakpoints('wide');

  return (
    <Surface border="all" color={1} overflow="hidden" radius="l">
      <Stack>
        <Stack hPadding="l" rowGap="xs" vPadding="l">
          <Title />
          <Text size="s" tone="muted" />
        </Stack>
        <Surface color={2} hPadding="l" vPadding="m">
          <Stack
            columnGap="m"
            direction={isWide ? 'row' : 'column'}
            rowGap="s"
            vAlign={isWide ? 'center' : 'stretch'}
          >
            <Text size="s" />
            <Stack columnGap="s" direction={isWide ? 'row' : 'column'} rowGap="s">
              <ButtonLink href="#" size="s" variant="secondary" />
              <ButtonLink href="#" size="s" />
            </Stack>
          </Stack>
        </Surface>
      </Stack>
    </Surface>
  );
}

<BreakpointsProvider breakpoints={productBreakpoints}>
  <ReleaseDesk />
</BreakpointsProvider>
```

</Example>
