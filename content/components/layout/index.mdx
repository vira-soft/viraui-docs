Layout components shape how content sits on the page — flex rows and columns, responsive grids, themed surfaces, dividers, and bleed when media should escape padded shells. Props map onto [spacing](/foundation/spacing) and [radius](/foundation/radius) tokens so rhythm stays on the theme scale instead of ad hoc CSS. When the React tree itself must branch at viewport width, [`Breakpoints`](/components/layout/breakpoints) pairs with [useBreakpoints](/get-started/utilities/use-breakpoints); when only styles need to shift, prefer CSS media queries. Your agent composes these hosts through `viraui-design` and package specs.
