---
title: Elevator
description: Apply resting and hover elevation hooks to child roots — no wrapper element.
---

`Elevator` is a renderless helper. It walks valid element children and merges [elevation](/foundation/elevation) data attributes (`data-elevation`, `data-elevation-hover`, `data-elevation-direction`) onto each child's root so preflight shadow styles activate without a wrapping `div`.

Set `resting` for the default level and optional `hover` for pointer elevation; `direction` controls which edge casts the shadow. Invalid nodes pass through unchanged.

Popup lists in [`Select`](/components/inputs/select) and [`Autocomplete`](/components/inputs/autocomplete) already sit on elevated surfaces. Use `Elevator` when a custom child needs the same shadow contract. [`Surface`](/components/layout/surface) has no elevation prop of its own.

## When to use

- A custom card or panel needs resting and/or hover shadow without an extra wrapper
- A floating bar should cast upward (`direction="top"`) toward content below
- You want the same elevation hooks Select and Autocomplete already use

## When not to use

- You only need background, border, or radius → [Surface](/components/layout/surface)
- The control already elevates its popup (Select, Autocomplete menus)
- Depth should come from nested color ramp layers alone → Surface `color`

## Related

- [Surface](/components/layout/surface) — panel chrome that Elevator typically wraps
- [Elevation](/foundation/elevation) — shadow levels and direction contract
- [Select](/components/inputs/select) — elevated popups that already own their own lift

## Common examples

### Resting shadow

A feature card with only `resting` keeps a steady soft shadow. Useful for static tiles and placeholder shells that should not lift on hover.

<Example preview={<ElevatorRestingDemo />}>

```tsx
import { Elevator, Stack, Surface, Text, Title } from '@viraui/react';

<Elevator resting={1}>
  <Surface
    border="all"
    color={1}
    hPadding="l"
    radius="m"
    render={<Stack rowGap="s" minWidth="16rem" />}
    vPadding="l"
  >
    <Title />
    <Text />
  </Surface>
</Elevator>
```

</Example>

### Hover lift

Pair `resting` with `hover` so the child root steps up on pointer hover. The usual interactive card pattern.

<Example preview={<ElevatorDemo />}>

```tsx
import { Elevator, Stack, Surface, Text } from '@viraui/react';

<Elevator resting={1} hover={4}>
  <Surface
    border="all"
    color={1}
    hPadding="l"
    radius="m"
    render={<Stack rowGap="s" minWidth="14rem" />}
    vPadding="l"
  >
    <Text />
    <Text size="s" tone="muted" />
  </Surface>
</Elevator>
```

</Example>

### Cast direction

`direction` picks which edge casts the shadow. Default is bottom for page cards; `top` suits floating bars that sit above content.

<Example preview={<ElevatorDirectionDemo />}>

```tsx
import { Elevator, Stack, Surface, Text } from '@viraui/react';

<Stack columnGap="l" direction="row" wrap>
  <Elevator resting={2}>
    <Surface border="all" color={1} hPadding="m" radius="m" vPadding="m">
      <Text />
      <Text size="s" tone="muted" />
    </Surface>
  </Elevator>
  <Elevator resting={2} direction="top">
    <Surface border="all" color={1} hPadding="m" radius="m" vPadding="m">
      <Text />
      <Text size="s" tone="muted" />
    </Surface>
  </Elevator>
</Stack>
```

</Example>
