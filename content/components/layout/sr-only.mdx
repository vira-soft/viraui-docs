---
title: SROnly
description: Visually hide copy while keeping it in the accessibility tree — classic clip recipe for AT-only text.
---

`SROnly` wraps children in a clipped span so the text stays in the accessibility tree without painting on screen. Use it when sighted UI already carries the meaning (heading, chips, compact fraction) and assistive tech still needs an extra phrase, name, or description.

Default root is a `span`. Pass `render` when the accessible text must live on another element while keeping the clip styles. Do not put focusable controls inside it, and do not mark the wrapper `aria-hidden` — that would remove the text from the tree.

Prefer a visible muted [`Text`](/components/typography/text) line when sighted users also need the guidance. Prefer `aria-label` on the control itself when a short name is enough and no shared label node is required.

---

## When to use

- Extra status or count that should not add visual chrome beside a heading
- Accessible name for an [`IconButton`](/components/actions/icon-button) via `aria-labelledby`
- Compact visible phrasing that needs fuller wording for screen readers (pagination, result counts)

## When not to use

- Sighted users also need the copy → [Text](/components/typography/text) `tone="muted"` (or Field helper)
- A short name belongs on the control → `aria-label` on [IconButton](/components/actions/icon-button) / Button
- You need to hide something from everyone → remove it from the tree, do not clip it
- Focusable controls or interactive widgets as children

## Common examples

### Inbox status

Keep the panel heading clean. Park the unread count in `SROnly` while a badge on the notifications control covers the visual cue.

<Example preview={<SROnlyInboxDemo />}>

```tsx
import { Bell } from '@phosphor-icons/react';
import { Badge, IconButton, Separator, SROnly, Stack, Surface, Title } from '@viraui/react';

<Surface border="all" color={1} radius="l">
  <Stack hPadding="m" rowGap="m" vPadding="m">
    <Stack direction="row" hAlign="space-between" vAlign="center">
      <Stack columnGap="s" direction="row" vAlign="center">
        <Title render={<h2 />} size="5">
          Inbox
        </Title>
        <SROnly>3 unread messages</SROnly>
      </Stack>
      <Badge color="yellow" show>
        <IconButton aria-label="Notifications" icon={<Bell />} size="s" variant="flat" />
      </Badge>
    </Stack>
    <Separator />
    {/* message rows */}
  </Stack>
</Surface>
```

</Example>

### Named toolbar action

Point `aria-labelledby` at an `SROnly` id when a toolbar glyph should stay unlabeled on screen. Sibling actions can keep a plain `aria-label`. Keep the strip as dense chrome — no empty preview band under it.

<Example preview={<SROnlyAssetToolbarDemo />}>

```tsx
import { ArrowsClockwise, DownloadSimple, ShareNetwork } from '@phosphor-icons/react';
import { IconButton, SROnly, Stack, Surface, Text } from '@viraui/react';

<Surface border="all" color={1} hPadding="m" radius="m" vPadding="s">
  <Stack direction="row" hAlign="space-between" vAlign="center">
    <Stack rowGap="2xs">
      <Text size="s" weight="semibold" />
      <Text size="xs" tone="muted" />
    </Stack>
    <Stack columnGap="s" direction="row" vAlign="center">
      <SROnly id="asset-refresh-label">Refresh canvas</SROnly>
      <IconButton
        aria-labelledby="asset-refresh-label"
        icon={<ArrowsClockwise />}
        radius="auto"
        size="s"
        variant="flat"
      />
      <IconButton aria-label="Download asset" icon={<DownloadSimple />} radius="auto" size="s" variant="flat" />
      <IconButton aria-label="Share asset" icon={<ShareNetwork />} radius="auto" size="s" variant="flat" />
    </Stack>
  </Stack>
</Surface>
```

</Example>

### Library results

Filter chips stay visible. An AT-only result count and compact `2 / 12` pagination with fuller screen-reader phrasing sit in the same library card.

<Example preview={<SROnlyLibraryDemo />}>

```tsx
import { CaretLeft, CaretRight } from '@phosphor-icons/react';
import { Chip, IconButton, Separator, SROnly, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} radius="l">
  <Stack hPadding="m" rowGap="m" vPadding="m">
    <Stack rowGap="xs">
      <Title render={<h2 />} size="5" />
      <Text size="s" tone="muted" />
    </Stack>
    <Stack columnGap="s" direction="row" vAlign="center" wrap>
      <Chip>Design</Chip>
      <Chip>Active</Chip>
      <SROnly>Showing 12 of 48 projects</SROnly>
    </Stack>
    {/* project rows — nested Surface radius="auto", rowGap="m" */}
    <Separator />
    <Stack
      columnGap="s"
      direction="row"
      hAlign="center"
      render={<nav aria-label="Pagination" />}
      vAlign="center"
    >
      <IconButton aria-label="Previous page" icon={<CaretLeft />} size="s" variant="flat" />
      <Text size="s">
        <SROnly>Page </SROnly>
        2
        <SROnly> of </SROnly>
        <span aria-hidden="true"> / </span>
        12
      </Text>
      <IconButton aria-label="Next page" icon={<CaretRight />} size="s" variant="flat" />
    </Stack>
  </Stack>
</Surface>
```

</Example>
