---
title: Stack
description: Flex layout host — direction, gap, alignment, and padding through theme tokens.
---

`Stack` is the default flex host in ViraUI. Reach for it whenever a single axis is enough: page sections, card internals, toolbars, form rows, and nested groups.

Children flow in a column or row. `direction`, `rowGap`, and `columnGap` map to [spacing](/foundation/spacing) tokens; `hAlign` / `vAlign` align from the consumer point of view. Padding props use the same step names as [`Surface`](/components/layout/surface); pass a `[start, end]` tuple when only one side needs inset.

Prefer `expandChildren` and `fullWidth` when a row of actions or a panel shell should fill the main axis. Pass `render` to swap the default `div` for a `header`, `nav`, `section`, or other semantic host while keeping the same layout hooks.

---

## When to use

- One flex axis is enough (vertical list, toolbar row, card internals)
- Gaps and padding should stay on the [spacing](/foundation/spacing) scale
- Nested groups need alignment without custom flex CSS
- The host should be a semantic landmark via `render`

## When not to use

- Fixed tracks, spans, or two-dimensional placement → [Grid](/components/layout/grid)
- Uneven tile heights in a column wall → [Masonry](/components/layout/masonry)
- Background, border, or radius chrome alone → [Surface](/components/layout/surface) (nest Stack inside for gaps)

## Common examples

### Column list

A vertical card list with token `rowGap` is the usual screen pattern. Each row is its own nested Stack for media, copy, and a trailing action.

<Example preview={<StackColumnDemo />}>

```tsx
import { Avatar, Button, Stack, Surface, Text } from '@viraui/react';

<Stack rowGap="m">
  <Surface border="all" color={1} hPadding="m" radius="m" vPadding="m">
    <Stack columnGap="m" direction="row" hAlign="space-between" vAlign="center">
      <Stack columnGap="m" direction="row" vAlign="center">
        <Avatar alt="" fallback="SC" size="s" src="…" />
        <Stack rowGap="xs">
          <Text />
          <Text size="s" tone="muted" />
        </Stack>
      </Stack>
      <Button size="s" variant="secondary" />
    </Stack>
  </Surface>
  {/* more cards */}
</Stack>
```

</Example>

### Equal-width row

`direction="row"` plus `expandChildren` grows direct children along the main axis so Cancel, Delete, and Save share the strip evenly. Pair with `fullWidth` when the stack itself must fill the parent.

<Example preview={<StackEqualRowDemo />}>

```tsx
import { FloppyDisk, Trash } from '@phosphor-icons/react';
import { Button, Stack } from '@viraui/react';

<Stack columnGap="m" direction="row" expandChildren fullWidth>
  <Button variant="secondary" />
  <Button addon={<Trash />} variant="destructive" />
  <Button addon={<FloppyDisk />} />
</Stack>
```

</Example>

### Nested padding

Outer and inner Stacks own section gaps and token padding. Header copy, body controls, and a footer bar stay on the spacing scale without custom flex CSS.

<Example preview={<StackNestedDemo />}>

```tsx
import { Button, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} overflow="hidden" radius="l">
  <Stack rowGap="m">
    <Stack hPadding="l" rowGap="xs" vPadding="l">
      <Title />
      <Text size="s" tone="muted" />
    </Stack>
    <Surface color={2} hPadding="l" vPadding="m">
      <Stack columnGap="m" direction="row" hAlign="space-between" vAlign="center">
        <Button variant="secondary" />
        <Button />
      </Stack>
    </Surface>
  </Stack>
</Surface>
```

</Example>

### Axis padding tuples

`hPadding` / `vPadding` accept a `[start, end]` tuple. Use `0` on one side for single-edge inset, or different tokens when start and end should not match. Prefer the tuple over custom `paddingBlock*` / `paddingInline*` CSS.

<Example preview={<StackAxisPaddingDemo />}>

```tsx
import { Button, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} overflow="hidden" radius="l">
  <Stack>
    <Stack hPadding="l" rowGap="xs" vPadding={['l', 0]}>
      <Title />
      <Text size="s" tone="muted" />
    </Stack>
    <Stack hPadding={['l', 'm']} rowGap="s" vPadding="m">
      <Stack direction="row" hAlign="space-between" vAlign="center">
        <Text size="s" />
        <Text size="xs" tone="muted" />
      </Stack>
    </Stack>
    <Stack hPadding="l" vPadding={[0, 'l']}>
      <Button size="s" variant="secondary" />
    </Stack>
  </Stack>
</Surface>
```

</Example>

### Semantic root

`render` swaps the default `div` for a native landmark while Stack still owns direction, gap, and padding. Useful for page chrome and nested `nav` clusters.

<Example preview={<StackSemanticDemo />}>

```tsx
import { ButtonLink, Stack, Text } from '@viraui/react';

<Stack
  columnGap="s"
  direction="row"
  fullWidth
  hAlign="space-between"
  hPadding="m"
  render={<header />}
  vAlign="center"
  vPadding="m"
>
  <Text />
  <Stack columnGap="xs" direction="row" render={<nav />} vAlign="center">
    <ButtonLink href="#" size="s" variant="secondary" />
    <ButtonLink href="#" size="s" variant="flat" />
    <ButtonLink href="#" size="s" variant="flat" />
  </Stack>
</Stack>
```

</Example>
