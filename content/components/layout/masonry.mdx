---
title: Masonry
description: Multi-column masonry layout — responsive column counts from breakpoint map.
---

`Masonry` packs children into a variable-height column grid. Each child is a `Masonry.Item`; the root measures its inline size and picks a column count from `breakpointCols`.

The default map opens more columns as the root grows. Pass your own `breakpointCols` object to replace that schedule: keys are min-width pixel thresholds against the Masonry root's content-box, and the largest matching breakpoint wins. Layout runs in the client after mount, so the first paint matches the `default` column count until `ResizeObserver` settles.

Compose each item as Elevator → [`Surface`](/components/layout/surface) → [`Stack`](/components/layout/stack) for chrome and spacing, and set `gap` from the spacing scale instead of custom column margins.

---

## When to use

- Image galleries, tag clouds, or card feeds where tile height varies
- Columns should reflow from the Masonry root width, not a fixed track grid
- You want packed columns rather than shared row heights

## When not to use

- Every row should share the same height, or items need spans → [Grid](/components/layout/grid)
- A single flex axis is enough → [Stack](/components/layout/stack)
- You only need a themed panel around content → [Surface](/components/layout/surface)

## Common examples

### Responsive gallery

A photo wall with uneven tile heights is the baseline Masonry layout. The built-in schedule applies unless you pass `breakpointCols`: one column by default, then more as the root grows.

<Example preview={<MasonryResponsiveGalleryDemo />}>

```tsx
import { Elevator, Masonry, Stack, Surface, Text, Title } from '@viraui/react';

<Masonry aria-label="Workspace photo gallery" gap="m">
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} overflow="hidden" radius="m">
        <Stack>
          <img alt="" height={160} src="…" width={480} />
          <Stack hPadding="m" rowGap="2xs" vPadding="m">
            <Title />
            <Text />
          </Stack>
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} overflow="hidden" radius="m">
        <Stack>
          <img alt="" height={240} src="…" width={480} />
          <Stack hPadding="m" rowGap="2xs" vPadding="m">
            <Title />
            <Text />
          </Stack>
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
</Masonry>
```

</Example>

### Custom breakpoints

Replace the default map when the wall should open columns at different root widths. Keys may arrive unsorted; the largest matching min-width still wins. Thresholds are measured on the Masonry root, not the viewport.

<Example preview={<MasonryCustomBreakpointsDemo />}>

```tsx
import { Elevator, Masonry, Stack, Surface, Text, Title } from '@viraui/react';

<Masonry
  aria-label="Campus zones"
  breakpointCols={{ default: 1, 640: 2, 1152: 3 }}
  gap="l"
>
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} radius="m">
        <Stack hPadding="l" rowGap="s" vPadding="l">
          <Title />
          <Text />
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} radius="m">
        <Stack hPadding="l" rowGap="s" vPadding="l">
          <Title />
          <Text />
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
</Masonry>
```

</Example>

### Variable-height tiles

Pack presentational Surface cards with uneven copy length so column flow stays visible. Reach for Grid instead when every tile should share a row height or needs spans and placement.

<Example preview={<MasonryVariableHeightDemo />}>

```tsx
import { Elevator, Masonry, Stack, Surface, Text } from '@viraui/react';

<Masonry aria-label="Editorial card wall" gap="l">
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} hoverColor={3} radius="m">
        <Stack hPadding="l" rowGap="s" vPadding="l">
          <Text />
          <Text />
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
  <Masonry.Item>
    <Elevator resting={1}>
      <Surface border="all" color={2} hoverColor={3} radius="m">
        <Stack hPadding="l" rowGap="s" vPadding="l">
          <Text />
          <Text />
        </Stack>
      </Surface>
    </Elevator>
  </Masonry.Item>
</Masonry>
```

</Example>
