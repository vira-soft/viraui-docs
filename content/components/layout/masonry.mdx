`Masonry` distributes children into a variable-height column grid — each child is a `Masonry.Item`, and the root measures its inline size to pick a column count from `breakpointCols`. The default map steps from one column on narrow viewports up to six on very wide screens; pass your own `breakpointCols` object to replace that schedule — keys are min-width pixel thresholds, and the largest matching breakpoint wins. Layout runs in the client after mount; prefer [`Grid`](/components/layout/grid) when every row shares the same height. Masonry fits image galleries, tag clouds, and card feeds where tile height varies.
