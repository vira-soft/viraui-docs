title: Surface
description: Themed container — color ramp, radius, border sides, and padding on one host.
---

`Surface` is the primary panel host in ViraUI — `color` maps onto the theme base ramp (`1`–`3` or named tokens), `radius` reads [radius](/foundation/radius) steps, and `border` picks which sides get a contrast edge. Horizontal and vertical padding use the spacing scale; nested surfaces can set `radius="auto"` so inner corners stay [concentric](/foundation/radius) with the parent's padding and rounding. `Surface` also publishes radius context descendants consume — menus, nested cards, and glow shells rely on it. Use `Surface` wherever a region needs a distinct background plane instead of bare page chrome.
