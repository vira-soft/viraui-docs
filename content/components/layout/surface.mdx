---
title: Surface
description: Themed container — color ramp, radius, border sides, and padding on one host.
---

`Surface` is the primary panel host in ViraUI — `color` maps onto the theme base ramp (`1`–`3` or named tokens), `radius` reads [radius](/foundation/radius) steps, and `border` picks which sides get a contrast edge. Horizontal and vertical padding use the spacing scale; nested surfaces can set `radius="auto"` so inner corners stay [concentric](/foundation/radius) with the parent's padding and rounding. `Surface` also publishes radius context descendants consume — menus, nested cards, and glow shells rely on it. Surface has no gap prop: nest a [`Stack`](/components/layout/stack) for child spacing, or pass `render={<Surface … />}` on Stack so chrome and layout share one DOM node. Pair with [`Elevator`](/components/layout/elevator) when the panel needs animated shadow lift — Surface itself has no elevation prop. Use `Surface` wherever a region needs a distinct background plane instead of bare page chrome.

## Common examples

### Color ramp

`color` picks a base ramp layer so stacked panels read as separate planes. A short workspace board shows layers `1`–`3` on the theme ramp.

<Example preview={<SurfaceColorRampDemo />}>

```tsx
import { Stack, Surface, Text } from '@viraui/react';

<Stack rowGap="s">
  <Surface border="all" color={1} hPadding="m" radius="m" vPadding="m">
    <Stack rowGap="xs">
      <Text />
      <Text size="s" tone="muted" />
    </Stack>
  </Surface>
  <Surface border="all" color={2} hPadding="m" radius="m" vPadding="m">
    <Stack rowGap="xs">
      <Text />
      <Text size="s" tone="muted" />
    </Stack>
  </Surface>
  <Surface border="all" color={3} hPadding="m" radius="m" vPadding="m">
    <Stack rowGap="xs">
      <Text />
      <Text size="s" tone="muted" />
    </Stack>
  </Surface>
</Stack>
```

</Example>

### Border sides

`border` accepts one side or a list — a right edge on a rail, bottom edges between rows — instead of drawing every edge. Omit the prop when the panel should stay borderless.

<Example preview={<SurfaceBorderSidesDemo />}>

```tsx
import { Stack, Surface, Text } from '@viraui/react';

<Surface border="all" color={1} overflow="hidden" radius="l">
  <Stack direction="row" expandChildren>
    <Surface border="right" color={2} hPadding="l" vPadding="l">
      <Stack rowGap="s">
        <Text />
        <Text />
        <Text />
      </Stack>
    </Surface>
    <Stack expandChildren>
      <Surface border="bottom" hPadding="l" vPadding="m">
        <Text />
      </Surface>
      <Surface hPadding="l" vPadding="m">
        <Text />
      </Surface>
    </Stack>
  </Stack>
</Surface>
```

</Example>

### Nested concentric

Set a large token `radius` on the outer host and `radius="auto"` on nested planes so each inset corner stays concentric with the parent's padding. A third nested Surface makes the step-down easier to see — reusing the same token on every layer leaves a flat double-radius look.

<Example preview={<SurfaceNestedConcentricDemo />}>

```tsx
import { Button, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} hPadding="l" radius="2xl" vPadding="l">
  <Stack rowGap="m">
    <Stack rowGap="xs">
      <Title />
      <Text />
    </Stack>
    <Surface border="all" color={2} hPadding="s" radius="auto" vPadding="s">
      <Surface border="all" color={3} hPadding="m" radius="auto" vPadding="m">
        <Stack direction="row" hAlign="space-between" vAlign="center">
          <Text />
          <Button />
        </Stack>
      </Surface>
    </Surface>
  </Stack>
</Surface>
```

</Example>

### Token padding

`hPadding` / `vPadding` inset the Surface on the spacing scale; Stack owns gaps between children. Compose with `render={<Surface … />}` when flex layout and chrome should share one node — a tinted footer strip can still be a nested Surface.

<Example preview={<SurfacePaddingComposeDemo />}>

```tsx
import { Button, Stack, Surface, Text, Title } from '@viraui/react';

<Stack render={<Surface border="all" color={1} overflow="hidden" radius="l" />}>
  <Stack hPadding="l" rowGap="m" vPadding="l">
    <Title />
    <Text />
  </Stack>
  <Surface color={2} hPadding="l" vPadding="m">
    <Stack direction="row" hAlign="space-between">
      <Button variant="secondary" />
      <Button />
    </Stack>
  </Surface>
</Stack>
```

</Example>
