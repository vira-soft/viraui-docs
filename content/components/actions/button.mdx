Button is the default **labeled** action control. Visible text names what happens when you activate it, and the control stays a real button for keyboard and assistive tech.

When the affordance should navigate (in-app route or external URL), use **ButtonLink** instead. It shares the same visual chrome but renders a native `<a>`, or a framework `Link` via `render`. Do not force `render={<a />}` on Button; Base UI keeps button semantics there.

Variants follow intent, not decoration: filled primary for the one commit action on a surface, secondary for cancel or peer choices, flat when the control should sit quietly in chrome, and destructive only when the action removes or cannot be undone. Optional `addon`, `pill`, and `loading` cover leading/trailing glyphs, capsule shape, and in-flight requests without jumping the layout.

---

## When to use

- A visible text label names the action (Save, Cancel, Delete, Download)
- Footer or dialog strips where several labeled actions share a row
- Navigation that should look like a button (`ButtonLink`) rather than plain text

## When not to use

- Icon-only chrome with no visible label → [IconButton](/components/actions/icon-button)
- A control that stays pressed and may swap icons → [ToggleButton](/components/actions/toggle-button)
- Tags, filters, or status pills that do not commit work → [Chip](/components/widgets/chip)

## Common examples

### Variants

Pick the variant from what the action means on that surface. A bare Button is already primary; reach for another variant when the action is not the commit.

<Example preview={<ButtonVariantsDemo />}>

```tsx
import { Button, Stack } from '@viraui/react';

<Stack direction="row" columnGap="m" wrap>
  <Button>Save</Button>
  <Button variant="secondary">Cancel</Button>
  <Button variant="flat">Learn more</Button>
  <Button variant="destructive">Delete</Button>
</Stack>
```

</Example>

Prefer one primary per region. Pair it with secondary cancel rather than two competing filled actions.

### Addons

Pass icons through `addon`, not as lone children. Leading is the default; set `addonPosition="end"` when the glyph trails the label. Button CSS sizes SVG descendants — glyph size comes from the button, not per-icon CSS.

<Example preview={<ButtonAddonDemo />}>

```tsx
import { Download, FloppyDisk, Trash } from '@phosphor-icons/react';
import { Button, Stack } from '@viraui/react';

<Stack direction="row" columnGap="m" wrap>
  <Button addon={<Download />}>Download</Button>
  <Button addon={<FloppyDisk />} addonPosition="end" variant="secondary">
    Save draft
  </Button>
  <Button addon={<Trash />} variant="destructive">
    Delete
  </Button>
</Stack>
```

</Example>

If the control has no visible text, switch to [IconButton](/components/actions/icon-button) with an accessible name — do not empty Button children and hope the icon is enough.

### Pill

`pill` rounds the control into a capsule. Nest it in a full-radius [Surface](/components/layout/surface) bar when the action should read as chrome inside a strip rather than a free-floating button — put supporting copy on one side and the capsule CTA on the other so the row stays balanced.

<Example preview={<ButtonPillDemo />}>

```tsx
import { Download } from '@phosphor-icons/react';
import { Button, Stack, Surface, Text } from '@viraui/react';

<Stack fullWidth>
  <Surface
    border="all"
    color={2}
    hPadding="s"
    overflow="hidden"
    radius="full"
    vPadding="s"
  >
    <Stack direction="row" columnGap="m" hAlign="space-between" vAlign="center">
      <Text hPadding="m" weight="semibold">
        Export ready
      </Text>
      <Button addon={<Download />} pill>
        Download
      </Button>
    </Stack>
  </Surface>
</Stack>
```

</Example>

### Loading

Turn on `loading` while the request runs. Width stays stable so the layout does not jump when the Spinner appears; the Spinner itself stays decorative because `aria-busy` already marks the control. On Button, loading also blocks activation; on ButtonLink there is no `disabled` prop — loading sets `aria-disabled` / `aria-busy` while the link stays activatable.

<Example preview={<ButtonLoadingDemo />}>

```tsx
import { Button } from '@viraui/react';

<Button loading>Publishing…</Button>
```

</Example>

Keep the same label text during the wait (or a short “…”) so the announced name stays continuous.

### Action rows

Footer and dialog strips are Stack rows of Buttons — gap and alignment live on the Stack, not on per-button width CSS. Here the three actions share the strip equally: `fullWidth` fills the parent, `expandChildren` grows each Button on the main axis.

<Example preview={<ButtonActionRowDemo />}>

```tsx
import { FloppyDisk } from '@phosphor-icons/react';
import { Button, Stack } from '@viraui/react';

<Stack direction="row" columnGap="m" expandChildren fullWidth>
  <Button variant="secondary">Cancel</Button>
  <Button variant="destructive">Delete</Button>
  <Button addon={<FloppyDisk />}>Save</Button>
</Stack>
```

</Example>

### As a link

Use ButtonLink when activation should navigate. Same chrome as Button; different element — a native `<a>`, or a framework `Link` via `render`.

<Example preview={<ButtonLinkDemo />}>

```tsx
import { ArrowRight, ArrowSquareOut, BookOpen } from '@phosphor-icons/react';
import { ButtonLink, Stack } from '@viraui/react';

<Stack direction="row" columnGap="m" wrap>
  <ButtonLink href="/docs" addon={<BookOpen />}>
    Documentation
  </ButtonLink>
  <ButtonLink
    href="/next"
    addon={<ArrowRight />}
    addonPosition="end"
    variant="secondary"
  >
    Continue
  </ButtonLink>
  <ButtonLink
    href="https://docs.viraui.dev"
    addon={<ArrowSquareOut />}
    addonPosition="end"
    rel="noreferrer"
    target="_blank"
    variant="flat"
  >
    External docs
  </ButtonLink>
</Stack>
```

```tsx
import Link from 'next/link';
import { ButtonLink } from '@viraui/react';

<ButtonLink render={<Link href="/docs" />}>Documentation</ButtonLink>
```

</Example>

Pass `href` for native or external URLs (`target` / `rel` when needed). Trailing addons suit “continue” and external destinations. Pass `render` for in-app framework routing. Icon-only navigation belongs on [IconButton](/components/actions/icon-button) (`IconButtonLink`).
