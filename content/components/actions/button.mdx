Button is the default labeled action control. Text children name the action; optional `addon` slots accept a leading or trailing icon (button CSS sizes SVG descendants — no per-glyph sizing). Pick `variant` for primary, secondary, flat, or destructive treatments, `size` for density, and `pill` when a fully rounded capsule fits the layout. `loading` keeps the control width stable, sets `aria-busy`, and shows a decorative Spinner while the async work runs. Reach for IconButton when there is no visible label, and ButtonLink when the affordance navigates with anchor semantics — do not force `render={<a />}` on Button.
