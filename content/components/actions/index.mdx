title: Actions
description: Interactive controls that commit work on the page — labeled buttons, link-shaped buttons, icon-only actions, and toggle primitives.
---

Actions are the controls that do something when activated — submit a form, follow a route with button chrome, flip a persistent pressed state, or run a compact toolbar cluster. ViraUI keeps labeled buttons, link-shaped buttons, icon-only variants, and toggle primitives separate so each keeps the right semantics (button, anchor, or pressed toggle) without fighting Base UI. Your agent reaches for this category when the screen needs a primary affordance, not a field input or floating overlay.
