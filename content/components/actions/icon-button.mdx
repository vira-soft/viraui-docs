title: IconButton
description: Icon-only button and its link twin — size, variant, pill, loading; IconButtonLink for navigation. Requires an accessible name on every instance.
---

IconButton wraps [Button](/components/actions/button) for compact, icon-only actions. Pass the glyph through `icon`; `size`, `variant`, `pill`, and `loading` follow the same chrome. The icon alone is not a name — every instance needs `aria-label` or `aria-labelledby`. Loading sets `aria-busy` and keeps the accessible name stable while the Spinner stays decorative.

When the affordance should navigate, use **IconButtonLink** instead. It shares the same visual chrome but keeps link semantics (`href`, or a framework `Link` via `render`). Do not force `render={<a />}` on IconButton. Reach for [ToggleButton](/components/actions/toggle-button) when the control needs a persistent pressed state or icon swap after interaction.

## Common examples
