IconButton wraps Button for compact, icon-only actions. Pass the glyph through `icon`; size, variant, `pill`, and `loading` follow the same model as Button. The icon alone is not a name — every instance needs `aria-label` or `aria-labelledby`. Loading sets `aria-busy` and keeps the accessible name stable while the Spinner stays decorative. Reach for ToggleButton when the control needs a persistent pressed state or icon swap after interaction, and IconButtonLink when the action navigates.
