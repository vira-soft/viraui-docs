---
title: ButtonLink
description: Link that shares Button visual chrome — href, framework Link render, addon, pill, and loading without button semantics.
---

ButtonLink looks like Button but navigates. It defaults to a native `<a>` and accepts `render` when your stack needs a framework `Link` (Next.js, React Router, and similar). The same `size`, `variant`, `addon`, `pill`, and `loading` chrome apply, but there is no `disabled` prop — loading surfaces `aria-disabled` and `aria-busy` on the link chrome only. Your agent picks ButtonLink whenever the affordance is navigation or an external URL, not an in-page command.
