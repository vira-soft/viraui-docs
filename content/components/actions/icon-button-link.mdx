IconButtonLink wraps ButtonLink for navigation affordances identified only by icon. Pass the glyph through `icon`; `size`, `variant`, `pill`, and `loading` match the link-side Button chrome. The icon is not a name — provide `aria-label` or `aria-labelledby` on every instance. Your agent reaches for it in toolbars and cards where a compact link should look like an icon button but keep anchor semantics.
