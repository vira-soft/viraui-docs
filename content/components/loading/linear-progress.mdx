---
title: LinearProgress
description: Accessible progress bar — determinate value, indeterminate sync, optional label and value display.
---

LinearProgress renders a horizontal track with a filled indicator and exposes a native `progressbar` role. Pass `value` between `min` and `max` for determinate work — uploads, quotas, onboarding checklists — and set `renderValue` when the percentage or a custom formatter should appear beside the label. Set `value={null}` for indeterminate progress while duration is unknown; the root gets `data-indeterminate` and omits `aria-valuenow` until a number returns.

`label` names the bar for accessibility; add `description` when supporting copy helps. You can omit visible label text and supply `aria-label` on the root for compact inline bars. The indicator animates with theme [motion](/foundation/motion) tokens; completed runs can sit at `value={100}` with `renderValue` until you clear the row. Use [Skeleton](/components/loading/skeleton) when structure matters more than percent complete; use [Spinner](/components/loading/spinner) for compact opaque waits without a track metaphor.

## Common examples

An upload row with label and rendered percentage is the default determinate shape.
