---

`LinearProgress` shows task progress on a compact horizontal track with a native `progressbar` role. Pass a numeric `value` when the percent is known (uploads, exports, checklists). Set `value={null}` while duration is unknown — the root gets `data-indeterminate` and omits `aria-valuenow` until a number returns.

`label` names the bar for accessibility; add `description` for supporting copy under the track, and `renderValue` when the percent (or a custom formatter) should sit beside the label. For a compact bar with no visible label, supply `aria-label` on the root instead. The indicator animates with theme [motion](/foundation/motion) tokens.

---

## When to use

- A task with a known percent or bounded numeric value (upload, export, checklist)
- Background work whose duration is unknown (`value={null}`)
- A labeled track where the percent itself should be visible (`renderValue`)

## When not to use

- Static capacity or score within a range (storage, quota) → [Meter](/components/widgets/meter)
- Layout placeholders while content structure loads → [Skeleton](/components/loading/skeleton)
- A short opaque wait with no track metaphor → [Spinner](/components/loading/spinner)
- An interactive value the user drags → [Slider](/components/inputs/slider)

## Common examples

### Labeled determinate

An upload or export row with `label`, a numeric `value`, and `renderValue` is the usual determinate shape. Optional `description` adds muted helper copy under the track.

<Example preview={<LinearProgressLabeledDemo />}>

```tsx
import { LinearProgress } from '@viraui/react';

<LinearProgress
  label="Upload"
  description="Uploading selected files."
  renderValue
  value={42}
/>
```

</Example>

### Custom value slot

Pass a function to `renderValue` when the readout needs units or counts instead of the default percent string. The callback receives the Base UI formatted string and the numeric `value` (`null` while indeterminate).

<Example preview={<LinearProgressCustomValueDemo />}>

```tsx
import { LinearProgress } from '@viraui/react';

<LinearProgress
  label="Export"
  description="Batch export running."
  value={64}
  renderValue={(_formatted, value) =>
    value == null ? '…' : `${value} of 100 files`
  }
/>
```

</Example>

### Indeterminate sync

When the job is running but the percent is unknown, pass `value={null}`. Keep a visible `label` and helper copy so the row still explains what is in flight.

<Example preview={<LinearProgressIndeterminateDemo />}>

```tsx
import { LinearProgress } from '@viraui/react';

<LinearProgress
  label="Syncing"
  description="Checking for updates."
  value={null}
/>
```

</Example>

### Track-only card

Inside a goal or summary card, drop the visible `label` and name the bar with `aria-label`. Surrounding [Surface](/components/layout/surface) and [Text](/components/typography/text) carry the headline and caption row.

<Example preview={<LinearProgressGoalDemo />}>

```tsx
import { LinearProgress, Stack, Surface, Text } from '@viraui/react';

<Surface color={2} hPadding="m" radius="m" vPadding="m">
  <Stack rowGap="m">
    <Text family="mono" size="xs" tone="muted" />
    <Text size="2xl" />
    <LinearProgress aria-label="Retirement progress" value={65} />
    <Stack columnGap="s" direction="row" hAlign="space-between" vAlign="center">
      <Text tone="muted" />
      <Text weight="semibold" />
    </Stack>
  </Stack>
</Surface>
```

</Example>
