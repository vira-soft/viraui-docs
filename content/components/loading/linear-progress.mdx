LinearProgress renders a horizontal track with a filled indicator and exposes a native `progressbar` role. Pass `value` between `min` and `max` for determinate work (uploads, quotas, onboarding checklists) and set `renderValue` when the percentage or a custom formatter should appear beside the label. Set `value={null}` for indeterminate progress while duration is unknown; the root gets `data-indeterminate` and omits `aria-valuenow` until a number returns.

`label` names the bar for accessibility; add `description` when supporting copy helps. You can omit visible label text and supply `aria-label` on the root for compact inline bars. The indicator animates with theme [motion](/foundation/motion) tokens.

## When to use

- A task with a known percent or bounded `value` / `min` / `max` (upload, export, checklist)
- Background work whose duration is unknown (`value={null}`)
- A labeled track where the percent itself should be visible (`renderValue`)

## When not to use

- Static capacity or score within a range (storage, quota) → [Meter](/components/widgets/meter)
- Layout placeholders while content structure loads → [Skeleton](/components/loading/skeleton)
- A short opaque wait with no track metaphor → [Spinner](/components/loading/spinner)
- An interactive value the user drags → [Slider](/components/inputs/slider)

## Common examples

### Labeled determinate

An upload row with label and rendered percentage is the default determinate shape.

<PreviewSlot label="LinearProgress preview" />

```tsx
import { LinearProgress, Stack } from '@viraui/react';

<Stack rowGap="m" minWidth="16rem">
  <LinearProgress label="Upload" value={40} min={0} max={100} renderValue />
</Stack>
```
