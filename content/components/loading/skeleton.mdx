---
title: Skeleton
description: Loading placeholders — fixed blocks or Skeleton.Overlay shaped to the content they replace.
---

Skeleton paints neutral placeholder blocks while real content is still fetching. Set explicit `width` and `height` (or let flex layout stretch them) for free-form rows — avatar circles use `radius="full"` on square dimensions. When the final layout already exists in markup, wrap the real node in `Skeleton.Overlay`: the overlay reads the child bounding box and paints a shimmer mask on top, so placeholders stay aligned when copy wraps or media aspect ratios differ.

Theme [radius](/foundation/radius) props round skeleton corners like other surfaces. Mark the hosting region `aria-busy="true"` (and an accessible name when the whole card loads) so assistive tech knows content is provisional. For view-transition handoffs from loading to loaded, put `view-transition-name: skeleton-overlay` on the transitioning wrapper — the overlay and revealed content can share one morph. Shimmer respects `prefers-reduced-motion`; disable animation with `animate={false}` when a static block reads better.

```tsx
import { Skeleton, Stack, Surface } from '@viraui/react';

<Surface aria-busy="true" aria-label="Loading profile" border="all" radius="l" hPadding="m" vPadding="m">
  <Stack direction="row" columnGap="m" vAlign="center">
    <Skeleton radius="full" height="3rem" width="3rem" />
    <Stack expandChildren rowGap="s">
      <Skeleton height="1rem" width="8rem" />
      <Skeleton height="0.875rem" width="5rem" />
    </Stack>
  </Stack>
</Surface>
```
