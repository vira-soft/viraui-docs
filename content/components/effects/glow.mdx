---
title: Glow
description: Pointer-following border highlight — proximity, spread, and optional rainbow or global gradient attachment.
---

Glow wraps content the same way [Beam](/components/effects/beam) does: a transparent [Surface](/components/layout/surface) shell with `radius`, and the visible card as a child Surface with `radius="auto"`. Pointer position drives a highlight arc along the rim.

Tune how near the pointer must be, how wide the arc reads, and whether a faint rim stays when the pointer is far away. Shared `globalHighlight` keeps one fixed gradient across several cards; turn it off — or use rainbow colors — when a single card should feel independent. Prefer Glow when the highlight should follow the pointer; continuous spin or pulse belongs on Beam.

Glow hides under coarse pointers and `prefers-reduced-motion`. Do not use it as keyboard focus or status chrome.

<Callout type="warn" title="Performance cost">
Glow tracks the pointer and paints CSS variables on every move. Prefer one focal instance, or a small shared grid, per view. Do not default-decorate every card on a dense page.
</Callout>

## When to use

- Feature cards where a pointer-driven rim adds polish without changing layout
- A small shared grid that should share one highlight gradient
- Pill list rows that need a subtle edge response on hover

## When not to use

- Continuous border spin, traveling line, or pulse → [Beam](/components/effects/beam)
- Keyboard focus or status indication (Glow is decorative only)
- Wallpapering every card on a dense dashboard

## Related

- [Beam](/components/effects/beam) — continuous animated border, line, or pulse
- [Surface](/components/layout/surface) — shell and nested card radius
- [ProgressiveBlur](/components/effects/progressive-blur) — edge fade over scroll or media

## Common examples

### Shared highlight grid

A small set of cards with shared `globalHighlight` is the baseline Glow pattern. Move the pointer across the row — the arc follows and the gradient stays consistent across shells.

<Example preview={<GlowGridDemo />}>

```tsx
import { Glow, Stack, Surface, Text, Title, type GlowProps } from '@viraui/react';

const glowProps: GlowProps = {
  borderColor: 'transparent',
  borderWidth: 1,
  fitContent: true,
  globalHighlight: true,
  proximity: 180,
  radius: 'l',
};

<Stack columnGap="m" direction="row" hAlign="center" maxWidth="36rem" rowGap="m" wrap>
  <Glow {...glowProps}>
    <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
      <Stack maxWidth="12rem" rowGap="s">
        <Title />
        <Text />
      </Stack>
    </Surface>
  </Glow>
  <Glow {...glowProps}>
    <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
      <Stack maxWidth="12rem" rowGap="s">
        <Title />
        <Text />
      </Stack>
    </Surface>
  </Glow>
</Stack>
```

</Example>

Set `globalHighlight={false}` when each card should own an independent gradient path.

### Rainbow highlight

`rainbowColors` switches to a multi-stop palette and forces shared attachment off — useful for a single featured card that should feel distinct from a shared grid.

<Example preview={<GlowRainbowDemo />}>

```tsx
import { Glow, Stack, Surface, Text, Title } from '@viraui/react';

<Glow borderOffset={0} fitContent radius="l" rainbowColors>
  <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
    <Stack maxWidth="18rem" rowGap="s">
      <Title />
      <Text />
    </Stack>
  </Surface>
</Glow>
```

</Example>

### Pill list rows

Tight proximity and a flush ring suit pill list rows inside a list shell. Glow stays decorative — row actions own the accessible labels.

<Example preview={<GlowReportRowDemo />}>

```tsx
import { DotsThreeVertical } from '@phosphor-icons/react';
import { Glow, IconButton, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} hPadding="m" radius="l" vPadding="m">
  <Stack rowGap="m">
    <Title />
    <Text />
    <Glow borderOffset={0} borderWidth={1} proximity={10} radius="full">
      <Surface
        color={2}
        hPadding="m"
        overflow="hidden"
        radius="full"
        vPadding="m"
      >
        <Stack
          columnGap="m"
          direction="row"
          hAlign="space-between"
          vAlign="center"
        >
          <Stack rowGap="s">
            <Text />
            <Text />
          </Stack>
          <IconButton
            aria-label="More actions"
            icon={<DotsThreeVertical size={16} />}
            pill
            size="s"
            variant="flat"
          />
        </Stack>
      </Surface>
    </Glow>
  </Stack>
</Surface>
```

</Example>
