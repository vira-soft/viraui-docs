---
title: Glow
description: Pointer-following border highlight — proximity, spread, and optional rainbow or global gradient attachment.
---

Glow wraps content the same way [Beam](/components/effects/beam) does: a transparent [Surface](/components/layout/surface) shell with `radius`, and the visible card as a child Surface with `radius="auto"`. Pointer position drives a highlight arc along the rim — `angleLag` softens how the arc follows (set `0` for instant snap). `proximity` is the distance from the edge where the glow reaches full strength; `spread` sets the arc width in degrees. Resting `opacity` keeps a faint rim visible when the pointer is far away (default is fully off until the pointer is near).

`borderWidth`, `borderColor`, and `borderOffset` shape the masked ring under the gradient. `glowColor` overrides the theme conic highlight; `rainbowColors` switches to a multi-stop palette and disables shared attachment. `globalHighlight` keeps one fixed gradient across cards when several Glow instances sit on the same page — turn it off when each card should feel independent. `fitContent` shrink-wraps the shell to the child. Prefer Glow when the highlight should follow the pointer; continuous spin or pulse belongs on Beam.

<Callout type="warn" title="Performance cost">
Glow tracks the pointer and paints CSS variables on every move. Prefer one focal instance, or a small shared grid, per view. Do not default-decorate every card on a dense page.
</Callout>

## Common examples

### Feature grid

A small set of cards with shared `globalHighlight` is the baseline Glow pattern. Move the pointer across the row — the arc follows and the gradient stays consistent across shells.

<GlowGridDemo />

```tsx
import { Glow, Stack, Surface, Text, Title, type GlowProps } from '@viraui/react';

const glowProps: GlowProps = {
  borderColor: 'transparent',
  borderWidth: 1,
  fitContent: true,
  globalHighlight: true,
  proximity: 180,
  radius: 'l',
};

function FeatureCard({
  description,
  title,
}: {
  description: string;
  title: string;
}) {
  return (
    <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
      <Stack maxWidth="12rem" rowGap="s">
        <Title render={<h3 />} size="5">
          {title}
        </Title>
        <Text render={<p />} size="s" tone="muted">
          {description}
        </Text>
      </Stack>
    </Surface>
  );
}

<Stack columnGap="m" direction="row" rowGap="m" wrap>
  <Glow {...glowProps}>
    <FeatureCard
      title="Design"
      description="Ship polished screens without reinventing chrome."
    />
  </Glow>
  <Glow {...glowProps}>
    <FeatureCard
      title="Build"
      description="Accessible primitives wired for agent-led builds."
    />
  </Glow>
  <Glow {...glowProps}>
    <FeatureCard
      title="Ship"
      description="Theme tokens and motion that stay on-brand."
    />
  </Glow>
  <Glow {...glowProps}>
    <FeatureCard
      title="Iterate"
      description="Tighten copy, spacing, and motion from real feedback."
    />
  </Glow>
</Stack>
```

Set `globalHighlight={false}` when each card should own an independent gradient path.

### Rainbow highlight

`rainbowColors` switches to a multi-stop palette and forces shared attachment off — useful for a single featured card that should feel distinct from a shared grid.

<GlowRainbowDemo />

```tsx
import { Glow, Stack, Surface, Text, Title } from '@viraui/react';

<Glow borderOffset={0} fitContent radius="l" rainbowColors>
  <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
    <Stack maxWidth="18rem" rowGap="s">
      <Title render={<h3 />} size="4">
        Featured plan
      </Title>
      <Text render={<p />} size="s" tone="muted">
        Move the pointer near the card to see the rainbow arc follow.
      </Text>
    </Stack>
  </Surface>
</Glow>
```

### Report rows

Tight `proximity` and a flush ring (`borderOffset={0}`, thin `borderWidth`) suit pill list rows inside a list shell. Glow stays decorative — row actions own the accessible labels.

<GlowReportRowDemo />

```tsx
import { DotsThreeVertical } from '@phosphor-icons/react';
import { Glow, IconButton, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" color={1} hPadding="m" radius="l" vPadding="m">
  <Stack rowGap="m">
    <Stack hAlign="center" rowGap="xs">
      <Title align="center" render={<h3 />} size="6">
        Recent reports
      </Title>
      <Text align="center" render={<p />} size="s" tone="muted">
        Move near a row to light the rim.
      </Text>
    </Stack>
    <Stack rowGap="s">
      <Glow borderOffset={0} borderWidth={1} proximity={10} radius="full">
        <Surface
          color={2}
          hPadding="m"
          overflow="hidden"
          radius="full"
          vPadding="m"
        >
          <Stack
            columnGap="m"
            direction="row"
            hAlign="space-between"
            vAlign="center"
          >
            <Stack rowGap="s">
              <Text weight="semibold">Q2 payout report</Text>
              <Text size="s" tone="muted">
                PDF · Updated 2 hours ago · 14 pages
              </Text>
            </Stack>
            <IconButton
              aria-label="More actions for Q2 payout report"
              icon={<DotsThreeVertical size={16} />}
              pill
              size="s"
              variant="flat"
            />
          </Stack>
        </Surface>
      </Glow>
    </Stack>
  </Stack>
</Surface>
```

Glow hides under coarse pointers and `prefers-reduced-motion`. Do not use it as keyboard focus or status chrome.
