---
title: Beam
description: Animated border shell — rotating edge, traveling line, or pulse glow around a child Surface.
---

Beam paints continuous motion around a child — a featured promo, a secondary CTA, or an empty-state icon. The root is a transparent [Surface](/components/layout/surface) that only sets `radius`; nest the real card as a child Surface with `radius="auto"` so both share one corner curve.

Pick the motion family with `variant`: a spinning border, a traveling line along the bottom, or a breathing pulse inside or outside the shell. Theme `color`, plus optional duration and strength knobs, keep the accent loud or quiet. Prefer Beam for rare focal moments; pointer-following highlights belong on [Glow](/components/effects/glow).

Off-screen beams pause so background tabs do not keep spinning. `fitContent` shrink-wraps the shell when the card should not stretch full width.

<Callout type="warn" title="Performance cost">
Beam keeps continuous motion on screen and can be heavy on CPU and memory. Prefer one focal instance per view. Do not wrap every card in a grid — reserve it for a single hero or CTA moment.
</Callout>

---

## When to use

- One featured card or CTA that should draw the eye without changing layout
- A quiet empty-state mark that needs a soft breathing accent
- Continuous spin, travel, or pulse — not a pointer-driven rim

## When not to use

- Pointer-following border highlight → [Glow](/components/effects/glow)
- Loading shimmer on static copy → [Shimmer](/components/typography/shimmer)
- Decorating every card in a dense grid (pick one focal Beam instead)

## Common examples

### Featured border

A rotating colorful border is the usual Beam composition. `fitContent` keeps the shell tight to the card; `radius="auto"` on the inner Surface matches the Beam corners.

<Example preview={<BeamBorderDemo />}>

```tsx
import { Beam, Button, Stack, Surface, Text, Title } from '@viraui/react';

<Beam color="colorful" fitContent radius="l" variant="border">
  <Surface border="all" color={2} hPadding="l" radius="auto" vPadding="l">
    <Stack maxWidth="18rem" rowGap="m">
      <Title />
      <Text />
      <Button />
    </Stack>
  </Surface>
</Beam>
```

</Example>

`size="s"` tightens the border beam for compact chrome; other variants ignore `size`.

### Line under a CTA

Wrap only the secondary action when a traveling bottom edge should call attention without a full border spin.

<Example preview={<BeamLineDemo />}>

```tsx
import { Beam, Button, ButtonLink, Stack, Text } from '@viraui/react';

<Stack columnGap="m" direction="row" vAlign="center">
  <Button />
  <Text />
  <Beam duration="5s" radius="m" strength={0.8} variant="line">
    <ButtonLink href="/pro" variant="secondary" />
  </Beam>
</Stack>
```

</Example>

### Pulse accent

`pulse-outside` breathes a bloom around the child — useful for empty-state icons and quiet focal marks. `pulse-inside` keeps the bloom clipped to the shell.

<Example preview={<BeamPulseDemo />}>

```tsx
import { Sparkle } from '@phosphor-icons/react';
import { Beam, Stack, Surface, Text, Title } from '@viraui/react';

<Stack hAlign="center" rowGap="l" vAlign="center">
  <Beam color="primary" fitContent radius="full" variant="pulse-outside">
    <Surface
      aria-hidden
      border="all"
      color={1}
      hPadding="m"
      radius="full"
      vPadding="m"
    >
      <Sparkle size={24} />
    </Surface>
  </Beam>
  <Stack hAlign="center" maxWidth="28ch" rowGap="s">
    <Title />
    <Text />
  </Stack>
</Stack>
```

</Example>

Beam is decorative only — accessible names and status live on the content inside, not on the shell.

## Ask your agent

```text tab="Promo beam"
Highlight the featured promo card with an animated border glow. Keep the card copy and padding unchanged — the effect should hug the card, not overpower it on small screens.
```

```text tab="Secondary CTA line"
Add a subtle traveling line under the Get Pro link next to the primary Sign in button so the upgrade path stands out without competing with the main action.
```

```text tab="Empty-state pulse"
Surround the empty-state icon with a soft breathing glow so the blank screen still has a quiet focal point. Keep the heading and helper text unchanged.
```

```text tab="Tone down"
The beam around this card feels too loud — soften the strength and switch to the primary brand color instead of the colorful palette.
```
