---
title: Typewriter
description: Inline typing animation — single phrase or cycling texts with caret styles and reduced-motion fallback.
---

Typewriter animates copy inside a `span` by writing characters into a typed layer while an `aria-live` region holds the full phrase for screen readers. Nest it inside [Title](/components/typography/title) or [Text](/components/typography/text) so size, tone, and heading level live on the parent — Typewriter stays the progressive reveal.

Pass a single string for one line, or a stable list of phrases to cycle with type, pause, delete, and loop timing. Choose a caret style (or none), and reserve layout space when surrounding flex rows should not jump while letters appear. Prefer Typewriter when progressive letter reveal is the intent; loading shimmer on static copy belongs on [Shimmer](/components/typography/shimmer).

<Callout type="warn" title="Reduced motion">
When `prefers-reduced-motion: reduce` is active, Typewriter skips straight to the full phrase (the last phrase when cycling). Do not rely on the typing effect alone to reveal critical information.
</Callout>

## When to use

- Marketing heroes that cycle a few short product lines
- A muted subtitle that should type once under a static title
- Blurbs that wrap and need reserved height while phrases cycle

## When not to use

- Loading shimmer on already-known static copy → [Shimmer](/components/typography/shimmer)
- Critical information that must appear immediately for every reader
- Inline arrays recreated each render (keep the phrase list stable)

## Related

- [Title](/components/typography/title) — display parent for hero cycles
- [Text](/components/typography/text) — body or muted parent for single phrases
- [Shimmer](/components/typography/shimmer) — moving highlight across static text

## Common examples

### Cycle text

Nest Typewriter in a display Title for marketing heroes. Reserved space holds the line box through type/delete; an underscore caret with a themed color matches the usual auth compose pattern.

<Example preview={<TypewriterHeroDemo />}>

```tsx
import { Button, Stack, Title, Typewriter } from '@viraui/react';

const heroTexts: string[] = [
  'Ship real UI at the speed of thought.',
  'Ship real UI at the speed of your LLM.',
  'Ship real UI at the speed of your team.',
];

<Stack rowGap="l">
  <Title lineHeight="s" maxWidth="32rem" render={<h1 />} size="1">
    <Typewriter
      caret="underscore"
      caretColor="var(--base-5)"
      preserveSpace
      texts={heroTexts}
    />
  </Title>
  <Stack columnGap="m" direction="row" wrap>
    <Button />
    <Button variant="secondary" />
  </Stack>
</Stack>
```

</Example>

Keep `texts` at module scope (or otherwise stable). Inline arrays recreate on every parent render and restart the cycle.

### Colored caret

String `children` type once under a static Title. An underscore caret with a highlight color lifts the mark above muted copy so the cursor reads as an accent while the phrase stays quiet.

<Example preview={<TypewriterMutedDemo />}>

```tsx
import { Stack, Text, Title, Typewriter } from '@viraui/react';

<Stack hAlign="center" rowGap="s">
  <Title />
  <Text size="s" tone="muted">
    <Typewriter caret="underscore" caretColor="var(--highlight-green)" delay={200} speed={35}>
      Quiet tools for night shoots — grade, mask, and ship.
    </Typewriter>
  </Text>
</Stack>
```

</Example>

### Reserved space

`preserveSpace` plus a constrained `maxWidth` on Text keeps multi-line height steady while phrases cycle. Hiding the caret softens the reveal when a blinking mark would compete with body rhythm.

<Example preview={<TypewriterWrapDemo />}>

```tsx
import { Stack, Surface, Text, Title, Typewriter } from '@viraui/react';

const wrapTexts: string[] = [
  'We build focused, useful tools for designers and developers.',
  'Ship calm systems that stay steady across teams and releases.',
];

<Surface border="all" color={1} hPadding="l" radius="l" vPadding="l">
  <Stack rowGap="m">
    <Title />
    <Text maxWidth="33ch" size="2xl" tone="muted">
      <Typewriter
        caret="none"
        delay={800}
        deleteSpeed={30}
        pause={2500}
        preserveSpace
        speed={20}
        texts={wrapTexts}
      />
    </Text>
  </Stack>
</Surface>
```

</Example>

Typewriter is decorative motion on labeled copy — parent Title/Text (or a surrounding region) owns the accessible name and any busy semantics.
