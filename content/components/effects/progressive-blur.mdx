---
title: ProgressiveBlur
description: Multi-layer edge blur — fades from full backdrop blur at one edge to clear at the opposite side.
---

ProgressiveBlur stacks masked `backdrop-filter` layers so blur strength ramps along one edge. `direction` picks which edge starts at full blur (`top`, `right`, `bottom`, or `left`). `blur` sets the maximum radius at that edge; `easing` and optional `steps` shape how the internal layers fall off (exponential is the default). The root is `aria-hidden` — a visual scrim, not interactive chrome.

Mount it absolutely at the edge of a scroll region or over media when content should dissolve under a soft veil instead of a hard clip. The parent needs something to blur through — photos, gradients, or scrolling prose behind the overlay — and ProgressiveBlur itself needs a positioned size (usually a band along the edge). Keep list content and any sticky CTA above the fade layer in z-order so actions stay clickable.

<Callout type="warn" title="Performance cost">
ProgressiveBlur paints several `backdrop-filter` layers. Prefer one or two edge bands on a focal scroll panel. Do not stack it on every card in a dense grid.
</Callout>

## Common examples

### Bottom fade over a reader

A tall scroll article with images is the usual ProgressiveBlur composition. Keep the blur band inside the scrollport (sticky zero-height shell + `100cqb` viewport) so the scrollbar stays sharp, pad the scroll content so the last lines can travel under the veil, and keep the footer CTA above the blur in z-order.

<Example preview={<ProgressiveBlurBottomDemo />}>

```tsx
import { Button, ProgressiveBlur, Stack, Surface } from '@viraui/react';

const panelStyle = {
  position: 'relative',
  blockSize: '28rem',
  maxInlineSize: '24rem',
  marginInline: 'auto',
} as const;

const bottomBlurStyle = {
  position: 'absolute',
  insetInline: 0,
  bottom: 0,
  blockSize: '8rem',
} as const;

<Surface border="all" color={1} overflow="hidden" radius="l" style={panelStyle}>
  <div
    style={{
      blockSize: '100%',
      containerType: 'size',
      overflow: 'auto',
    }}
  >
    <div
      aria-hidden
      style={{
        position: 'sticky',
        top: 0,
        blockSize: 0,
        pointerEvents: 'none',
        zIndex: 1,
      }}
    >
      <div
        style={{
          position: 'absolute',
          insetInline: 0,
          top: 0,
          blockSize: '100cqb',
        }}
      >
        <ProgressiveBlur blur="24px" direction="bottom" style={bottomBlurStyle} />
      </div>
    </div>
    {/* long prose + images */}
  </div>
  <Stack
    hAlign="center"
    hPadding="l"
    style={{
      position: 'absolute',
      insetInline: 0,
      bottom: 0,
      zIndex: 2,
      paddingBlockEnd: '1rem',
    }}
  >
    <Button />
  </Stack>
</Surface>
```

</Example>

`direction="bottom"` is the default — set it only when the code should read the edge explicitly.

### Top fade under sticky chrome

Flip the band to `direction="top"` when sticky title chrome should stay sharp while scrolling content softens underneath. Keep the blur inside the scrollport with the same sticky zero-height shell so the scrollbar stays sharp. ProgressiveBlur has no tint prop — layer a fading `background` on the same band to darken the backdrop under the blur. Pad the scroll content so the first lines sit past the strong end of the veil without leaving a large empty gap.

<Example preview={<ProgressiveBlurTopDemo />}>

```tsx
import { ProgressiveBlur, Stack, Surface, Text, Title } from '@viraui/react';

const panelStyle = {
  position: 'relative',
  blockSize: '28rem',
  maxInlineSize: '24rem',
  marginInline: 'auto',
} as const;

const topBlurStyle = {
  position: 'absolute',
  insetInline: 0,
  top: 0,
  blockSize: '9rem',
  zIndex: 1,
  background:
    'linear-gradient(to bottom, color-mix(in oklab, var(--global-background) 88%, transparent), transparent)',
} as const;

<Surface border="all" color={1} overflow="hidden" radius="l" style={panelStyle}>
  <Stack
    hPadding="l"
    rowGap="xs"
    style={{
      position: 'absolute',
      insetInline: 0,
      top: 0,
      zIndex: 2,
      paddingBlock: '0.85rem',
    }}
    vPadding="s"
  >
    <Title />
    <Text />
  </Stack>
  <div
    style={{
      blockSize: '100%',
      containerType: 'size',
      overflow: 'auto',
    }}
  >
    <div
      aria-hidden
      style={{
        position: 'sticky',
        top: 0,
        blockSize: 0,
        pointerEvents: 'none',
        zIndex: 1,
      }}
    >
      <div
        style={{
          position: 'absolute',
          insetInline: 0,
          top: 0,
          blockSize: '100cqb',
        }}
      >
        <ProgressiveBlur blur="28px" direction="top" style={topBlurStyle} />
      </div>
    </div>
    {/* long prose + images — paddingBlockStart ~7rem under the veil */}
  </div>
</Surface>
```

</Example>

### Dual-edge long read

Top and bottom bands together suit a sheet-style reader: content softens under both the header and the footer action without clipping. Mount both bands in the same sticky scrollport shell so neither covers the scrollbar. Reuse the same tinted top band as the sticky-chrome example.

<Example preview={<ProgressiveBlurDualDemo />}>

```tsx
import { Button, ProgressiveBlur, Stack, Surface, Title } from '@viraui/react';

const panelStyle = {
  position: 'relative',
  blockSize: '30rem',
  maxInlineSize: '26rem',
  marginInline: 'auto',
} as const;

const topBlurStyle = {
  position: 'absolute',
  insetInline: 0,
  top: 0,
  blockSize: '9rem',
  zIndex: 1,
  background:
    'linear-gradient(to bottom, color-mix(in oklab, var(--global-background) 88%, transparent), transparent)',
} as const;

const bottomBlurStyle = {
  position: 'absolute',
  insetInline: 0,
  bottom: 0,
  blockSize: '8rem',
} as const;

<Surface border="all" color={1} overflow="hidden" radius="l" style={panelStyle}>
  <Stack
    hAlign="center"
    hPadding="l"
    style={{
      position: 'absolute',
      insetInline: 0,
      top: 0,
      zIndex: 2,
      paddingBlock: '0.85rem',
    }}
  >
    <Title />
  </Stack>
  <div
    style={{
      blockSize: '100%',
      containerType: 'size',
      overflow: 'auto',
    }}
  >
    <div
      aria-hidden
      style={{
        position: 'sticky',
        top: 0,
        blockSize: 0,
        pointerEvents: 'none',
        zIndex: 1,
      }}
    >
      <div
        style={{
          position: 'absolute',
          insetInline: 0,
          top: 0,
          blockSize: '100cqb',
        }}
      >
        <ProgressiveBlur blur="24px" direction="top" style={topBlurStyle} />
        <ProgressiveBlur blur="24px" direction="bottom" style={bottomBlurStyle} />
      </div>
    </div>
    {/* long prose + images — top ~7rem under the veil, bottom ~7rem for CTA */}
  </div>
  <Stack
    hAlign="center"
    hPadding="l"
    style={{
      position: 'absolute',
      insetInline: 0,
      bottom: 0,
      zIndex: 2,
      paddingBlockEnd: '1rem',
    }}
  >
    <Button variant="secondary" />
  </Stack>
</Surface>
```

</Example>

Tune `blur` when the veil feels too soft or too heavy; reach for `easing` or `steps` only when banding shows at the defaults.

ProgressiveBlur is decorative only — accessible names and actions live on the content and chrome above it, not on the scrim.
