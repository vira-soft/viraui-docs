---
title: StaticNoise
description: SVG grain overlay — turbulence filter with optional animated seed cycling and blend-mode control.
---

StaticNoise paints a full-bleed decorative grain layer as a `figure` with an internal SVG turbulence filter. It is always `aria-hidden` — texture on top of photography, gradients, or [Surface](/components/layout/surface) fills, not information. `opacity` and `mixBlendMode` (default `difference`) control how strongly the grain reads against what sits underneath; `baseFrequency` adjusts the noise scale.

Set `animate` to cycle `feTurbulence` seed values for living static — leave it off for a fixed grain plate. The filter id is scoped with `useId`, so multiple instances on one screen stay isolated. Position the figure absolutely over the target region (`inset: 0` on a `position: relative` parent) and keep interactive content in a sibling layer above the noise.

<Callout type="warn" title="Performance cost">
StaticNoise runs SVG turbulence and is memory-heavy. Prefer one focal overlay per view. Do not wallpaper every card in a dense grid.
</Callout>

## Common examples

### Hero grain

A gradient hero with a fixed grain wash is the usual StaticNoise composition. Content sits above the figure so CTAs stay clickable while the plate still blends through the scene.

<Example preview={<StaticNoiseHeroDemo />}>

```tsx
import { Button, Stack, StaticNoise, Surface, Text, Title } from '@viraui/react';

const overlayStyle = {
  position: 'absolute',
  inset: 0,
  zIndex: 1,
} as const;

const contentStyle = {
  position: 'relative',
  zIndex: 2,
} as const;

<Surface
  overflow="hidden"
  radius="l"
  style={{
    position: 'relative',
    maxInlineSize: '28rem',
    backgroundImage:
      'linear-gradient(145deg, var(--highlight-indigo) 0%, var(--highlight-blue) 48%, var(--highlight-green) 100%)',
  }}
>
  <StaticNoise opacity={0.28} style={overlayStyle} />
  <Stack hPadding="xl" rowGap="m" style={contentStyle} vPadding="xl">
    <Title />
    <Text />
    <Button />
  </Stack>
</Surface>
```

</Example>

`opacity={0.28}` lifts the grain a notch above the default so it reads on a dark gradient.

### Living static

`animate` cycles seed frames for a living grain plate — useful on a single vibrant product card where the atmosphere should feel awake without a motion accent like [Beam](/components/effects/beam).

<Example preview={<StaticNoiseAnimatedDemo />}>

```tsx
import { Button, Stack, StaticNoise, Surface, Text, Title } from '@viraui/react';

const overlayStyle = {
  position: 'absolute',
  inset: 0,
  zIndex: 1,
} as const;

const contentStyle = {
  position: 'relative',
  zIndex: 2,
} as const;

<Surface
  border="all"
  color={2}
  data-vibrant
  overflow="hidden"
  radius="l"
  style={{ position: 'relative', maxInlineSize: '22rem' }}
>
  <StaticNoise animate opacity={0.22} style={overlayStyle} />
  <Stack hPadding="l" rowGap="m" style={contentStyle} vPadding="l">
    <Title />
    <Text />
    <Button variant="secondary" />
  </Stack>
</Surface>
```

</Example>

### Soft-light on photography

Raise `baseFrequency` and switch `mixBlendMode` to `soft-light` when grain should sit like film over a photo instead of a hard difference plate. Caption chrome stays above the overlay.

<Example preview={<StaticNoisePhotoDemo />}>

```tsx
import { Stack, StaticNoise, Surface, Text, Title } from '@viraui/react';

const overlayStyle = {
  position: 'absolute',
  inset: 0,
  zIndex: 1,
} as const;

<Surface
  overflow="hidden"
  radius="l"
  style={{
    position: 'relative',
    maxInlineSize: '24rem',
    blockSize: '22rem',
    backgroundImage: 'url(…)',
    backgroundPosition: 'center',
    backgroundSize: 'cover',
  }}
>
  <StaticNoise
    baseFrequency={0.65}
    mixBlendMode="soft-light"
    opacity={1}
    style={overlayStyle}
  />
  <Stack
    hPadding="l"
    rowGap="xs"
    style={{
      position: 'absolute',
      insetInline: 0,
      bottom: 0,
      zIndex: 2,
      paddingBlock: '1.25rem',
      background:
        'linear-gradient(to top, color-mix(in oklab, black 55%, transparent), transparent)',
    }}
  >
    <Title />
    <Text />
  </Stack>
</Surface>
```

</Example>

StaticNoise is decorative only — accessible names and actions live on the content above it, not on the grain plate.
