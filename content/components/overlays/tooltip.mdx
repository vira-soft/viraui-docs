Tooltip shows a short hint when someone hovers or focuses a trigger. It is never the only place critical information should live. Wrap the app once in `Tooltip.Provider` at the root (same overlay shell as [Setup](/get-started/setup)) so open and close delays stay consistent across every tooltip on the page.

Each instance pairs `Tooltip.Trigger` with `Tooltip.Content`. The trigger accepts any control through `render`, including [IconButton](/components/actions/icon-button) with an `aria-label` when the glyph alone would be ambiguous. Content stays brief — a [Text](/components/typography/text) node or a short phrase. For icon-only controls, repeat the accessible name in the tooltip so sighted hover matches what screen readers hear.

---

## When to use

- A short label or clarification on hover/focus for a control that already has an accessible name
- Icon-only toolbar buttons where the visible hint should match `aria-label`
- Shared delay across many tooltips via one `Tooltip.Provider`

## When not to use

- The surface needs interaction, a title, or dismiss controls → [Popover](/components/overlays/popover)
- A list of commands from a trigger → [Menu](/components/overlays/menu)
- Essential instructions that must stay visible without hover → put them in on-page copy

## Common examples

### Matching label

A labeled button with matching hint text is the baseline pattern. Prefer the provider default delay in product UI; zero delay is for demos only. The demos below wrap `Tooltip.Provider` locally so the sandbox stays self-contained — in an app, mount the provider once at the root.

<Example preview={<TooltipLabelDemo />}>

```tsx
import { Button, Text, Tooltip } from '@viraui/react';

<Tooltip.Provider>
  <Tooltip>
    <Tooltip.Trigger render={<Button>Bold</Button>} />
    <Tooltip.Content>
      <Text>Bold</Text>
    </Tooltip.Content>
  </Tooltip>
</Tooltip.Provider>
```

</Example>

### Icon-only toolbar

Repeat each control’s `aria-label` in the tooltip so hover matches what screen readers hear. Same bordered toolbar chrome as the vertical [Separator](/components/layout/separator) editor strip. Do not hide essential instructions in tooltips alone.

<Example preview={<TooltipToolbarDemo />}>

```tsx
import {
  FloppyDisk,
  MagnifyingGlass,
  TextAlignLeft,
  TextB,
  TextItalic,
} from '@phosphor-icons/react';
import {
  IconButton,
  Separator,
  Stack,
  Surface,
  Text,
  Tooltip,
} from '@viraui/react';

<Tooltip.Provider>
  <Surface border="all" color={1} hPadding="2xs" radius="m" vPadding="2xs">
    <Stack columnGap="2xs" direction="row" vAlign="stretch">
      <Tooltip>
        <Tooltip.Trigger
          render={
            <IconButton
              aria-label="Bold"
              icon={<TextB />}
              size="s"
              variant="flat"
            />
          }
        />
        <Tooltip.Content>
          <Text size="s">Bold</Text>
        </Tooltip.Content>
      </Tooltip>
      <Tooltip>
        <Tooltip.Trigger
          render={
            <IconButton
              aria-label="Italic"
              icon={<TextItalic />}
              size="s"
              variant="flat"
            />
          }
        />
        <Tooltip.Content>
          <Text size="s">Italic</Text>
        </Tooltip.Content>
      </Tooltip>
      <Tooltip>
        <Tooltip.Trigger
          render={
            <IconButton
              aria-label="Align left"
              icon={<TextAlignLeft />}
              size="s"
              variant="flat"
            />
          }
        />
        <Tooltip.Content>
          <Text size="s">Align left</Text>
        </Tooltip.Content>
      </Tooltip>
      <Separator orientation="vertical" />
      <Tooltip>
        <Tooltip.Trigger
          render={
            <IconButton
              aria-label="Find in document"
              icon={<MagnifyingGlass />}
              size="s"
              variant="flat"
            />
          }
        />
        <Tooltip.Content>
          <Text size="s">Find in document</Text>
        </Tooltip.Content>
      </Tooltip>
      <Tooltip>
        <Tooltip.Trigger
          render={
            <IconButton
              aria-label="Save draft"
              icon={<FloppyDisk />}
              size="s"
              variant="flat"
            />
          }
        />
        <Tooltip.Content>
          <Text size="s">Save draft</Text>
        </Tooltip.Content>
      </Tooltip>
    </Stack>
  </Surface>
</Tooltip.Provider>
```

</Example>

Detached triggers and multiple triggers sharing one content surface use `Tooltip.createHandle()`; payload render props swap copy when the active trigger changes.
