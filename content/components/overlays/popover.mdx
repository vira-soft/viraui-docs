Popover opens a floating panel beside or below a trigger without blocking the rest of the page. Compose `Popover.Trigger` and `Popover.Sheet` as children of `Popover`. The trigger accepts any control through `render`; the sheet carries the accessible name through required `title` (plus optional `description`) on the styled variant.

Content portals out of the DOM flow, picks a side from available space, and dismisses on outside click or Escape. Same overlay family as [Menu](/components/overlays/menu), but sized for richer panels rather than command rows. Use styled `Popover.Sheet` when ViraUI chrome is enough; pass `unstyled` when you own the surface and still need `Popover.Title` / `Popover.Description` for the dialog name.

## When to use

- Options, notifications, or short forms anchored to a control without blocking the page
- Panels that need a title, description, body stack, and an explicit dismiss action
- Hover-open or focus-trapped interactive sheets (`openOnHover`, `modal="trap-focus"`)

## When not to use

- A list of commands or exclusive picks from a trigger → [Menu](/components/overlays/menu)
- A brief read-only hint with no interaction → [Tooltip](/components/overlays/tooltip)
- A modal task that should block the page → [Dialog](/components/dialogs/dialog)

## Common examples

### Titled sheet

A titled sheet with trigger, body stack, and `Popover.Close` is the default non-modal panel. Keep body copy short; put dense command lists in Menu instead.

<PreviewSlot label="Popover preview" />

```tsx
import { Button, Popover, Stack, Text } from '@viraui/react';

<Popover>
  <Popover.Trigger render={<Button variant="secondary">Options</Button>} />
  <Popover.Sheet title="Options" description="Choose an action">
    <Stack rowGap="m">
      <Text />
      <Popover.Close render={<Button variant="flat">Done</Button>} />
    </Stack>
  </Popover.Sheet>
</Popover>
```

Interactive panels can set `modal="trap-focus"` so tab cycles stay inside the sheet while it is open. Detached or multi-trigger layouts share one sheet through `Popover.createHandle()`; payload render props morph content when the active trigger changes. Do not wrap [Menu](/components/overlays/menu) in Popover.
