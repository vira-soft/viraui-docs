Popover opens a floating panel beside or below a trigger without blocking the rest of the page. Compose `Popover.Trigger` and `Popover.Sheet` as children of `Popover`. The trigger accepts any control through `render`; the sheet carries the accessible name through required `title` (plus optional `description`) on the styled variant.

Content portals out of the DOM flow, picks a side from available space, and dismisses on outside click or Escape. Same overlay family as [Menu](/components/overlays/menu), but sized for richer panels rather than command rows. Use styled `Popover.Sheet` when ViraUI chrome is enough; pass `unstyled` when you own the surface and still need `Popover.Title` / `Popover.Description` for the dialog name.

---

## When to use

- Options, notifications, or short forms anchored to a control without blocking the page
- Panels that need a title, description, body stack, and an explicit dismiss action
- Hover-open or focus-trapped interactive sheets (`openOnHover`, `modal="trap-focus"`)

## When not to use

- A list of commands or exclusive picks from a trigger → [Menu](/components/overlays/menu)
- A brief read-only hint with no interaction → [Tooltip](/components/overlays/tooltip)
- A modal task that should block the page → [Dialog](/components/dialogs/dialog)

## Common examples

### Titled sheet

A titled sheet with trigger, body stack, and `Popover.Close` is the default non-modal panel. Keep body copy short; put dense command lists in Menu instead.

<Example preview={<PopoverSheetDemo />}>

```tsx
import { Button, Popover, Stack, Text } from '@viraui/react';

<Popover>
  <Popover.Trigger render={<Button variant="secondary">Options</Button>} />
  <Popover.Sheet title="Options" description="Choose an action">
    <Stack rowGap="m">
      <Text />
      <Popover.Close render={<Button variant="secondary">Done</Button>} />
    </Stack>
  </Popover.Sheet>
</Popover>
```

</Example>

### Notifications

Open a short status panel from an icon-only [IconButton](/components/actions/icon-button). Match the accessible name on the trigger to what the sheet is about.

<Example preview={<PopoverNotificationsDemo />}>

```tsx
import { Bell } from '@phosphor-icons/react';
import { Button, IconButton, Popover, Stack, Text } from '@viraui/react';

<Popover>
  <Popover.Trigger
    render={
      <IconButton
        aria-label="Open notifications"
        icon={<Bell />}
        variant="secondary"
      />
    }
  />
  <Popover.Sheet title="Notifications" description="You are all caught up">
    <Stack rowGap="m">
      <Text />
      <Popover.Close render={<Button variant="secondary">Dismiss</Button>} />
    </Stack>
  </Popover.Sheet>
</Popover>
```

</Example>

### Focus trap

Interactive panels can set `modal="trap-focus"` so tab cycles stay inside the sheet while it is open. Use this when the sheet includes a text field or other controls that should not leak focus to the page.

<Example preview={<PopoverFocusTrapDemo />}>

```tsx
import { Button, Popover, Stack, Textfield } from '@viraui/react';

<Popover modal="trap-focus">
  <Popover.Trigger render={<Button>Sign in</Button>} />
  <Popover.Sheet title="Sign in" description="Focus stays inside the popover while open.">
    <Stack rowGap="m">
      <Textfield label="Email" placeholder="you@example.com" />
      <Stack direction="row" columnGap="s">
        <Button>Submit</Button>
        <Button variant="secondary">Reset</Button>
        <Popover.Close render={<Button variant="flat">Close</Button>} />
      </Stack>
    </Stack>
  </Popover.Sheet>
</Popover>
```

</Example>

### Shared handle

Detached or multi-trigger layouts share one sheet through `Popover.createHandle()`; payload render props morph content when the active trigger changes. Here each team row is the trigger — hover or click the whole card. Do not wrap [Menu](/components/overlays/menu) in Popover.

<Example preview={<PopoverHandleDemo />}>

```tsx
import { useState } from 'react';
import { Avatar, Button, Popover, Stack, Surface, Text } from '@viraui/react';

const handle = Popover.createHandle();

<>
  <Popover.Trigger
    closeDelay={100}
    handle={handle}
    openOnHover
    payload={{ name: 'Sarah Chen', role: 'Product Design' }}
    render={
      <Surface
        color={2}
        hPadding="m"
        radius="m"
        render={<button type="button" />}
        vPadding="m"
      />
    }
  >
    <Stack direction="row" columnGap="m" vAlign="center">
      <Avatar alt="Sarah Chen" fallback="SC" size="s" src="/avatar.jpg" />
      <Stack rowGap="s">
        <Text weight="semibold">Sarah Chen</Text>
        <Text size="s" tone="muted">
          Product Design
        </Text>
      </Stack>
    </Stack>
  </Popover.Trigger>
  <Popover handle={handle}>
    {({ payload }) =>
      payload ? (
        <Popover.Sheet title={payload.name} description={payload.role} headerAlign="center">
          <Stack hAlign="center" rowGap="m">
            <Text />
            <Popover.Close
              render={
                <Button size="s" variant="secondary">
                  View profile
                </Button>
              }
            />
          </Stack>
        </Popover.Sheet>
      ) : null
    }
  </Popover>
</>
```

</Example>
