Popover opens a floating panel beside or below a trigger without blocking the rest of the page. Compose `Popover.Trigger` and `Popover.Sheet` as children of `Popover`; the trigger accepts any control through `render`, and the sheet carries the accessible name through required `title` (plus optional `description`) on the styled variant. Content portals out of the DOM flow, picks a side from available space, and dismisses on outside click or Escape — same overlay family as [Menu](/components/overlays/menu), but sized for richer panels rather than command rows.

Use the styled `Popover.Sheet` when ViraUI chrome is enough. Pass `unstyled` when you own the surface — then compose `Popover.Title` and `Popover.Description` with [Title](/components/typography/title) and [Text](/components/typography/text) so the dialog name still resolves. Interactive panels can set `modal="trap-focus"` so tab cycles stay inside the sheet while it is open. Hover-open panels use `openOnHover`, `delay`, and `closeDelay` on the trigger. Detached or multi-trigger layouts share one sheet through `Popover.createHandle()` — the handle links triggers outside the root to a single popover instance, and payload render props morph content when the active trigger changes. Do not wrap [Menu](/components/overlays/menu) in Popover; Menu already owns portal and menu keyboard behavior. For modal tasks that block the page, use [Dialog](/components/dialogs/dialog) instead.

## Common examples

A notifications sheet with a dismiss control is the default shape — trigger, titled sheet, body stack, and `Popover.Close`.

<PreviewSlot label="Popover preview" />

```text tab="Notifications sheet"
Add an Options popover from a secondary button — title Options, short description, body copy, and a Done dismiss action.
```

```tsx
import { Button, Popover, Stack, Text } from '@viraui/react';

<Popover>
  <Popover.Trigger render={<Button variant="secondary">Options</Button>} />
  <Popover.Sheet title="Options" description="Choose an action">
    <Stack rowGap="m">
      <Text render={<p />}>Notification preferences and workspace shortcuts live here.</Text>
      <Popover.Close render={<Button variant="flat">Done</Button>} />
    </Stack>
  </Popover.Sheet>
</Popover>
```
