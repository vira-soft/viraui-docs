The components layer is where `@viraui/react` turns foundation tokens into composable UI. Each component belong to a specific category so your agent can map a screen to the right family:

- **Actions** commit work
- **Dialogs** interrupt for focused tasks or transient feedback
- **Effects** add decorative motion and atmosphere
- **Inputs** collect data
- **Layout** structure pages and spacing
- **Loading** hold space while data arrives
- **Navigation** navigate content in place
- **Overlays** show interactive and contextual actions
- **Typography** set body, headings, and text treatments
- **Widgets** show compact status at a glance

Component pages cover wiring, live previews, and copy-ready prompts against package specs and consumer skills. Prop detail stays in `@viraui/react` source and specs; these pages teach the contract so you can review agent output without memorizing every export or property.
