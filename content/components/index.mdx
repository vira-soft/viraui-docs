The components layer is where `@viraui/react` turns foundation tokens into composable UI. Categories follow Storybook so your agent can map a screen to the right family — actions commit work, inputs collect data, overlays float above the page, widgets show compact status at a glance. Component pages cover wiring, live previews, and copy-ready prompts against package specs and consumer skills. Prop detail stays in `@viraui/react` source and specs; these pages teach the contract so you can review agent output without memorizing every export.
