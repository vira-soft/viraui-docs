---
title: Chip
description: Compact label pill with primary, secondary, outline, or highlight variants and optional decorative addon.
---

Chip is a small, non-submitting label for tags, filters, and metadata. Children render as the label through [Text](/components/typography/text); `variant` selects primary, secondary, outline, or a foundation highlight name.

Optional `addon` accepts an icon or other node on the start or end side. The slot is `aria-hidden` because the label text should carry meaning. Base UI `render` can swap the root when the chip should look like a pill but behave as a link. On filled [Button](/components/actions/button) surfaces, chips often need `data-mode="inverted"` so contrast holds against the button fill.

---

## When to use

- Tags, filters, or status pills that do not commit work
- Compact metadata beside a row or inside a filter strip

## When not to use

- Activation that commits work → [Button](/components/actions/button) or [ToggleButton](/components/actions/toggle-button)
- Icon-only chrome with no label → [IconButton](/components/actions/icon-button)
- Corner status on another control → [Badge](/components/widgets/badge)

---

## Related

- [Button](/components/actions/button) — labeled actions that commit
- [ToggleButton](/components/actions/toggle-button) — pressed-state filters that activate
- [Badge](/components/widgets/badge) — decorative corner status on a host

## Common examples

### Status pill

Use filled primary, muted secondary, and one highlight for status — not a row of every highlight token. Reach for `outline` when the pill should sit quieter than a fill.

<Example preview={<ChipStatusDemo />}>

```tsx
import { Chip, Stack } from '@viraui/react';

<Stack columnGap="s" direction="row" wrap>
  <Chip>Paid</Chip>
  <Chip variant="secondary">Pending</Chip>
  <Chip variant="red">Overdue</Chip>
</Stack>
```

</Example>

### Addon

`addon` is decorative and `aria-hidden`. Put meaning in the label. Default side is start; set `addonPosition="end"` when the glyph should trail.

<Example preview={<ChipAddonDemo />}>

```tsx
import { CheckCircle, Tag } from '@phosphor-icons/react';
import { Chip, Spinner, Stack } from '@viraui/react';

<Stack columnGap="s" direction="row" wrap>
  <Chip addon={<CheckCircle />} variant="outline">
    Verified
  </Chip>
  <Chip addon={<Tag />} addonPosition="end" variant="outline">
    Billing
  </Chip>
  <Chip
    addon={<Spinner aria-hidden size="s" variant="dots" />}
    addonPosition="end"
    variant="blue"
  >
    Syncing
  </Chip>
</Stack>
```

</Example>

### As a link

`render` replaces the default `div` when the pill should navigate. Chip keeps pill chrome (`data-no-link-style`) and still is not a submit control — use [Button](/components/actions/button) when the action commits work.

<Example preview={<ChipLinkDemo />}>

```tsx
import { ArrowSquareOut } from '@phosphor-icons/react';
import { Chip } from '@viraui/react';

<Chip
  addon={<ArrowSquareOut />}
  addonPosition="end"
  render={<a href="/docs" />}
>
  API docs
</Chip>
```

</Example>
