---

Avatar shows a person or entity in a fixed circular frame. Pass `src` and `alt` when a photo exists; always supply `fallback` (initials or a short node) so Base UI can render that layer when the image is missing or fails.

`size` picks the footprint and scales the fallback label through the shared [Text](/components/typography/text) map. The root stays a non-growing `span`, so avatars hold steady in toolbars and list rows. Pair a single face with a name in [Stack](/components/layout/stack); use [AvatarGroup](/components/widgets/avatar-group) when several identities should overlap on one line.

---

## When to use

- One person or entity face beside a name, row, or menu trigger
- Photo when a URL exists; initials only as the image-error path

## When not to use

- Several overlapping collaborators → [AvatarGroup](/components/widgets/avatar-group)
- A clickable chrome control with no face → [IconButton](/components/actions/icon-button)

## Common examples

### Face beside name

A photo next to a name is the usual row. Always pass `fallback` even when `src` is set — that layer is the image-error path, not a second visual for people who already have a photo.

<Example preview={<AvatarNameRowDemo />}>

```tsx
import { Avatar, Stack, Text } from '@viraui/react';

<Stack columnGap="m" direction="row" vAlign="center">
  <Avatar
    alt="Lara Thompson"
    fallback="LT"
    src="https://mockmind-api.uifaces.co/content/human/80.jpg"
  />
  <Stack rowGap="xs">
    <Text weight="semibold">Lara Thompson</Text>
    <Text size="s" tone="muted">
      Design lead
    </Text>
  </Stack>
</Stack>
```

</Example>

### Missing image

Omit `src` only when teaching initials. The required `fallback` then becomes the visible face.

<Example preview={<AvatarFallbackDemo />}>

```tsx
import { Avatar, Stack, Text } from '@viraui/react';

<Stack columnGap="m" direction="row" vAlign="center">
  <Avatar fallback="NP" />
  <Stack rowGap="xs">
    <Text weight="semibold">Noah Patel</Text>
    <Text size="s" tone="muted">
      No photo on file
    </Text>
  </Stack>
</Stack>
```

</Example>

### Two sizes

Default size is `s`. Reach for `m` when the face needs a bit more presence in a toolbar — skip an xs-through-l catalog.

<Example preview={<AvatarSizesDemo />}>

```tsx
import { Avatar, Stack, Surface } from '@viraui/react';

<Surface border="all" color={1} hPadding="s" radius="m" vPadding="s">
  <Stack columnGap="s" direction="row" vAlign="center">
    <Avatar
      alt="Mia Chen"
      fallback="MC"
      src="https://mockmind-api.uifaces.co/content/human/81.jpg"
    />
    <Avatar
      alt="Elena Rossi"
      fallback="ER"
      size="m"
      src="https://mockmind-api.uifaces.co/content/human/82.jpg"
    />
  </Stack>
</Surface>
```

</Example>

## Ask your agent

```text tab="Member list avatars"
Show an avatar before each name in this member list. Use profile photos when URLs exist; otherwise initials. Keep avatars non-interactive — navigation belongs on the row or a separate button.
```

```text tab="Missing photo"
This teammate has no photo. Show initials in the avatar and keep their name beside it.
```

```text tab="Toolbar faces"
Put two teammate avatars in a small bordered toolbar — default size for one, a bit larger for the other. Photos when you have URLs, initials as fallback.
```
