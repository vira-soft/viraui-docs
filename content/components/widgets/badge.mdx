---
title: Badge
description: Wraps content with an animated corner status dot — toggle show, position, highlight color, and dot diameter.
---

Badge wraps any child and optionally paints a decorative status dot on a corner. The child stays fully interactive. Common hosts are [Avatar](/components/widgets/avatar), [IconButton](/components/actions/icon-button), or [Chip](/components/widgets/chip). `show` toggles the dot and the radial mask cutout; `position` picks the corner (`top-end` by default).

`color` maps to a foundation highlight token; `size` sets the dot diameter. Enter and exit animate the hole and dot in sequence, and the motion collapses immediately when `prefers-reduced-motion` is on. The dot is decorative: pair it with visible copy or an accessible name on the wrapped control when the status matters to everyone.

---

## When to use

- Unread, online, or attention cues on an existing control
- A corner glyph that should animate in and out with `show`

## When not to use

- A labeled status pill in a row → [Chip](/components/widgets/chip)
- Help text that must be readable on its own → [Tooltip](/components/overlays/tooltip) or body copy

## Common examples

### Presence on a host

Wrap an [Avatar](/components/widgets/avatar) and toggle `show` when presence changes. Default corner is `top-end`. The dot is decorative — keep status in nearby copy or a labeled control.

<Example preview={<BadgePresenceDemo />}>

```tsx
import { Avatar, Badge, Switch } from '@viraui/react';

<Badge color="green" show>
  <Avatar
    alt="Lara Thompson"
    fallback="LT"
    size="m"
    src="https://mockmind-api.uifaces.co/content/human/80.jpg"
  />
</Badge>
<Switch label="Online" />
```

</Example>

### Unread on IconButton

The [IconButton](/components/actions/icon-button) keeps `aria-label`. Other corners exist; reach for them only when the default `top-end` collides with the host.

<Example preview={<BadgeUnreadDemo />}>

```tsx
import { Bell } from '@phosphor-icons/react';
import { Badge, IconButton } from '@viraui/react';

<Badge show>
  <IconButton aria-label="Notifications" icon={<Bell />} />
</Badge>
```

</Example>
