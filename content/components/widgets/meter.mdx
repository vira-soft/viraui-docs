Meter displays a scalar value on a track using Base UI meter semantics — `value`, `min`, and `max` feed an accessible `progressbar` that users do not drag. Optional `label` renders through the shared `FieldLabel` pattern; `description` adds muted helper copy below the track; `renderValue` shows the current amount beside the label (boolean for default formatting or a function for custom text). The indicator width follows `value` automatically. Use Meter for storage quotas, completion percentages, or any read-only fill level; use [Slider](/components/inputs/slider) when someone must adjust the value, and [LinearProgress](/components/loading/linear-progress) for indeterminate or route-level loading bars without a numeric model.
