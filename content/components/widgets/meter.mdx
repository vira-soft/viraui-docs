Meter shows a scalar value on a track with Base UI meter semantics. `value`, `min`, and `max` feed an accessible `progressbar` that users do not drag. Optional `label` uses the shared field-label pattern; `description` adds muted helper copy below the track; `renderValue` shows the current amount beside the label (boolean for default formatting, or a function for custom text).

The indicator width follows `value` automatically. Reach for Meter when the fill level is known and read-only — storage quotas, completion percentages, capacity. Use [Slider](/components/inputs/slider) when someone must adjust the value, and [LinearProgress](/components/loading/linear-progress) for indeterminate or route-level loading without a numeric model.

## When to use

- Known min/max fill levels the user should see but not edit
- Quotas, completion, or capacity with an optional formatted readout

## When not to use

- Interactive adjustment → [Slider](/components/inputs/slider)
- Indeterminate or route loading without a numeric model → [LinearProgress](/components/loading/linear-progress)
