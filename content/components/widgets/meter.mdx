---

`Meter` shows a scalar value on a track with Base UI meter semantics. `value`, `min`, and `max` feed an accessible meter that users do not drag. Optional `label` uses the shared field-label pattern; `description` adds muted helper copy below the track; `renderValue` shows the current amount beside the label (`true` for default formatting, or a function for custom text).

The indicator width follows `value` automatically. Reach for Meter when the fill level is known and read-only — storage quotas, completion percentages, capacity. Use [Slider](/components/inputs/slider) when someone must adjust the value, and [LinearProgress](/components/loading/linear-progress) for in-progress tasks or indeterminate work.

---

## When to use

- Known min/max fill levels the user should see but not edit
- Quotas, completion, or capacity with an optional formatted readout

## When not to use

- Interactive adjustment → [Slider](/components/inputs/slider)
- In-progress or indeterminate task progress → [LinearProgress](/components/loading/linear-progress)

## Common examples

### Labeled value

A labeled meter with `renderValue` is the baseline dashboard pattern. Optional `description` clarifies what the fill represents.

<Example preview={<MeterLabeledDemo />}>

```tsx
import { Meter } from '@viraui/react';

<Meter
  label="Storage"
  description="74 GB of 100 GB used."
  renderValue
  value={74}
/>
```

</Example>

### Custom value slot

Pass a function to `renderValue` when the readout needs units instead of the default formatted string. The callback receives the Base UI formatted string and the numeric `value`.

<Example preview={<MeterCustomValueDemo />}>

```tsx
import { Meter } from '@viraui/react';

<Meter
  label="Storage used"
  description="42 GB of 100 GB used."
  value={42}
  renderValue={(_formatted, value) => `${value} GB`}
/>
```

</Example>

### Highlight variants

Use highlight `variant` names when the track and indicator should share a semantic color — health, warning, danger. Stack a few related metrics; do not dump every highlight token.

<Example preview={<MeterHighlightDemo />}>

```tsx
import { Meter, Stack } from '@viraui/react';

<Stack rowGap="xl">
  <Meter
    label="Health"
    description="Uptime across the last 30 days."
    renderValue
    value={92}
    variant="green"
  />
  <Meter
    label="Latency"
    description="p95 response time vs budget."
    renderValue
    value={38}
    variant="yellow"
  />
  <Meter
    label="Errors"
    description="Failed requests this hour."
    renderValue
    value={12}
    variant="red"
  />
</Stack>
```

</Example>
