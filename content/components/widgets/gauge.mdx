---
title: Gauge
description: Composable round dial for determinate readings and optional polar slider control — linear bars stay on Slider or Meter.
---

`Gauge` builds a round dial from SVG parts that share one domain — track, arc, zones, ticks, needle, value text, and insets. Pass `value`, `min`, and `max` on the root; compose only the parts the reading needs. Wrap with `GaugeControl` when the dial should also adjust the value on a polar arc (single or dual thumb).

Reach for Gauge when the metaphor is polar: KPI rings, instrument chrome, nested arcs. Prefer [Meter](/components/widgets/meter) for a compact horizontal capacity bar, [Slider](/components/inputs/slider) for a linear interactive track, [IconMeter](/components/widgets/icon-meter) for discrete icon-row scores, and [LinearProgress](/components/loading/linear-progress) for in-progress or indeterminate work. Part color is optional. Every part paints from the theme without a `color` prop, so the default composition needs none — and the dial follows mode/theme changes for free. Set color only where it carries a meaning (severity bands, a `zoneColor`-driven arc, chrome you must separate); restating a part's own default is a no-op that pins it to a literal token. Any valid CSS color works: `#hex`, named colors, `oklch()`, `var(--*)`. Gauge has no Meter-style `variant`.

Always name read-only dials with `label` (or `aria-label`), and always pass `label` on `GaugeControl`.

## Anatomy

Import the component and assemble its parts:

```tsx
import {
  Gauge,
  GaugeArc,
  GaugeControl,
  GaugeDot,
  GaugeHub,

  GaugeMarks,
  GaugeNeedle,

  GaugeTickLabels,

<GaugeControl>
  <Gauge>

```

## When to use

- Determinate readings on a round dial (rings, needles, zone bands, nested insets)
- Polar single or dual-thumb adjustment with `GaugeControl`

## When not to use

- Compact horizontal capacity the user only reads → [Meter](/components/widgets/meter)
- Discrete icon-row scores (stars, hearts, pips) → [IconMeter](/components/widgets/icon-meter)
- Linear interactive range on a track → [Slider](/components/inputs/slider)
- In-progress or indeterminate task progress → [LinearProgress](/components/loading/linear-progress)

## Common examples

### Simple dial

Track, arc, and a large centered value are the baseline read-only dial. Add parts only when the reading needs them.

<Example preview={<GaugeSimpleDemo />}>

```tsx

  <GaugeTrack />
  <GaugeArc />
  <GaugeValue fontSize={104} />
</Gauge>
```

</Example>

### Zones and needle

Zone bands plus a pointer needle read as instrument chrome. Keep tick density modest; let `zoneCutoffs` drive marks at band edges.

<Example preview={<GaugeZonesNeedleDemo />}>

```tsx
import {
  Gauge,
  GaugeHub,
  GaugeMarks,
  GaugeNeedle,
  GaugeText,
  GaugeTickLabels,
  GaugeTicks,
  GaugeValue,
  GaugeZones,
  zoneCutoffs,
  type Zone,
} from '@viraui/react';

const zones: Zone[] = [
  { to: 180, color: 'var(--global-contrast)' },
  { to: 240, color: 'var(--global-primary)' },
];

<Gauge
  value={128}
  min={0}
  max={240}
  startAngle={40}
  endAngle={320}
  fit="content"
  label="Speed"
>
  <GaugeZones zones={zones} width={8} gap={0} cap="butt" endCap="butt" />
  <GaugeMarks values={zoneCutoffs(zones)} length={8} width={2} />
  <GaugeTicks count={12} length={18} width={3} offset={-16} cap="butt" />
  <GaugeTicks count={48} length={8} width={1.5} offset={-12} cap="butt" opacity={0.6} />
  <GaugeTickLabels count={12} offset={-54} fontSize={20} weight="semibold" />
  <GaugeNeedle kind="pointer" length={0.85} width={10} tail={32} />
  <GaugeHub radius={12} />
  <GaugeValue fontSize={44} font="mono" weight="semibold" />
  <GaugeText fontSize={18}>km/h</GaugeText>
</Gauge>
```

</Example>

### Nested inset

`GaugeInset` nests child dials on the same polar plane — concentric activity rings, or a secondary fuel arc beside a primary needle.

<Example preview={<GaugeNestedInsetDemo />}>

```tsx
  stand: 'var(--highlight-cyan)',
  exercise: 'var(--highlight-acid)',
  move: 'var(--highlight-red)',
} as const;

<Gauge value={72} min={0} max={100} startAngle={180} endAngle={540} label="Move">
  <GaugeTrack width={44} color={RING.move} opacity={0.18} />
  <GaugeArc width={44} color={RING.move} />
  <GaugeValue fontSize={52} weight="bold" />

    <GaugeArc width={76} color={RING.stand} />
```

```tsx
</Gauge>
```

</Example>

### Timer and clock

Full-circle time dials share `startAngle={180}` / `endAngle={540}` (twelve at the top). A clock uses hour + minute needles with `turns={12}` on the minute hand and `clockLabel` on the hours; a timer is a 0–60 ring with a mono second readout; a chronograph adds a sweeping second hand plus a minute-register `GaugeInset`.

### Value tooltip

`GaugeTooltip` paints a small elevated bubble next to the dial — default content is an optional `label` over the formatted value and `unit`. With `position="value"` it sits outward from the reading on the arc (here near the end of the fill). Hover, press, or focus shows it; pass `open` to keep it up. In an iframe or docs sandbox, pass `container` to that document’s `body` so the portal stays with the dial.

<Example preview={<GaugeTooltipDemo />}>

```tsx
import {
  Gauge,
  GaugeArc,
  GaugeDot,
  GaugeText,
  GaugeTooltip,
  GaugeTrack,
  GaugeValue,
} from '@viraui/react';

<Gauge value={32} min={0} max={50} startAngle={60} endAngle={300} label="Data usage">
  <GaugeTrack width={28} />
  <GaugeArc width={28} />
  <GaugeDot radius={7} />
  <GaugeTooltip label="Used" unit="GB" decimals={1} position="value" />
  <GaugeValue fontSize={96} weight="bold" />
  <GaugeText fontSize={32}>GB</GaugeText>
</Gauge>
```

</Example>

### Interactive control

Wrap the dial in `GaugeControl` for polar adjustment. Keep Control angles aligned with the child `Gauge`; pass `label` on Control and hide decorative dial chrome from AT with `aria-hidden` when Control owns the name.

<Example preview={<GaugeInteractiveControlDemo />}>

```tsx
import {
  Gauge,
  GaugeArc,
  GaugeControl,
  GaugeDot,
  GaugeHub,
  GaugeTicks,
  GaugeTrack,
  GaugeValue,
} from '@viraui/react';

<GaugeControl
  value={volume}
  onChange={setVolume}
  min={0}
  max={100}
  startAngle={40}
  endAngle={320}
  label="Volume"
  knob
>
  <Gauge
    value={volume}
    min={0}
    max={100}
    startAngle={40}
    endAngle={320}
    padding={56}
    aria-hidden
  >
    <GaugeHub radius={156} color="var(--global-contrast)" />
    <GaugeTrack width={6} opacity={0.12} offset={-18} />
    <GaugeArc width={6} offset={-18} />
    <GaugeTicks count={20} length={12} width={3} offset={6} cap="round" />
    <GaugeDot radius={11} offset={-76} />
    <GaugeValue fontSize={64} weight="bold" />
  </Gauge>
</GaugeControl>
```

</Example>

### Part colors

Parts already resolve to theme defaults — **omitting `color` is the normal, complete composition**, and the dial follows mode/theme changes for free. Reach for paint only when it carries a meaning the dial cannot show otherwise: severity bands, a reading that follows `zoneColor`, or chrome the composition must separate. Don't restate a part's own default as an explicit color: it changes nothing and pins the part to a literal token.

When you do need paint, pass any valid CSS color string on parts and `zones[].color` — hex, named colors, `oklch()`, or theme `var(--*)`. Drive the live arc with `zoneColor` so the fill tracks the active band as the value moves.

<Example preview={<GaugeTokenColorsDemo />}>

```tsx
import {
  Gauge,
  GaugeArc,
  GaugeTrack,
  GaugeValue,
  GaugeZones,
  zoneColor,
  type Zone,
} from '@viraui/react';

const zones: Zone[] = [
  { to: 20, color: '#e11d48' },
  { to: 70, color: 'goldenrod' },
  { to: 100, color: 'var(--highlight-green)' },
];

<Gauge value={value} min={0} max={100} label="Health">
  <GaugeTrack width={16} opacity={0.35} />
  <GaugeArc
    width={16}
    color={zoneColor(zones, value, 'var(--global-foreground)')}
  />
  <GaugeZones zones={zones} width={5} offset={-18} gap={1} cap="butt" endCap="round" />
  <GaugeValue fontSize={64} />
</Gauge>
```

</Example>
