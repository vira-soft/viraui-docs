---
title: ClampText
description: Multi-line truncation — rows limit with optional inline mode and render for custom roots.
---

ClampText applies `-webkit-line-clamp` through a `rows` prop (default `1`) so long strings ellipsize instead of breaking card layout. Set `inline` when the clamped span must sit inside running copy — inline mode uses `-webkit-inline-box` so the truncation flows with surrounding [Text](/components/typography/text). `render` swaps the root through Base UI semantics when the clamped node should be a `p`, `a`, or another element while keeping the same clamp styles.

Put the full string in `title` when hover should reveal the untruncated value — ClampText does not expand on its own. For single-line table cells and card titles, `rows={1}` is enough; descriptions in dense lists often need `rows={2}` or `rows={3}`. Nested composition works both ways: ClampText inside Title for a clamped heading line, or Title inside ClampText when the whole heading block must truncate as one unit.
