---
title: ClampText
description: Multi-line truncation — row limit with optional inline mode and render for custom roots.
---

ClampText truncates overflowing copy to a fixed row count so long strings ellipsize instead of breaking card or table layout. Set `rows` for how many lines show (default `1`); put the full string in `title` when hover should reveal the untruncated value — ClampText does not expand on its own.

Use `inline` when the clamped span must sit inside running [Text](/components/typography/text). `render` swaps the root when the clamped node should be a `p`, `a`, or another element while keeping the same clamp styles. Nested composition works both ways: ClampText inside Title for a clamped heading line, or Title inside ClampText when the whole heading block must truncate as one unit.

---

## When to use

- Card titles and descriptions in fixed-height tiles
- Table cells and dense list rows that must not wrap unbound
- Linked titles that still need clean single-line truncation

## When not to use

- Copy that should wrap fully at the body scale → [Text](/components/typography/text)
- Scaling a short display line to fill width → [FitText](/components/typography/fit-text)
- Headings that always show in full → [Title](/components/typography/title) alone

---

## Related

- [Text](/components/typography/text) — body-scale running copy
- [Title](/components/typography/title) — heading presets (often wrapped or nested)
- [FitText](/components/typography/fit-text) — fit-to-width instead of ellipsis

## Common examples

### Multi-line card description

A two-line card description that ellipsizes inside a fixed-height tile. Pair with a one-line clamped title when both lines compete for space.

<Example preview={<ClampTextCardDemo />}>

```tsx
import { ClampText, Stack, Surface, Text, Title } from '@viraui/react';

<Surface border="all" radius="l" hPadding="m" vPadding="m">
  <Stack maxWidth="16rem" rowGap="s">
    <Title />
    <ClampText
      render={<Text size="s" tone="muted" />}
      rows={2}
      title="Northwind Analytics keeps shared dashboards, scheduled exports, and access reviews in one workspace so regional teams can publish without duplicating reports."
    >
      Northwind Analytics keeps shared dashboards, scheduled exports, and
      access reviews in one workspace so regional teams can publish without
      duplicating reports.
    </ClampText>
  </Stack>
</Surface>
```

</Example>

### Clamped heading line

Nest ClampText inside [Title](/components/typography/title) when the heading must stay a heading and still ellipsize to one line. Hover `title` carries the full string.

<Example preview={<ClampTextHeadingDemo />}>

```tsx
import { ClampText, Title } from '@viraui/react';

<Title render={<h3 />} size="4">
  <ClampText title="Q3 pipeline review for EMEA enterprise renewals">
    Q3 pipeline review for EMEA enterprise renewals
  </ClampText>
</Title>
```

</Example>

### Inline clamp

Pass `inline` when a long fragment sits inside a sentence and should ellipsize without breaking the line into a block.

<Example preview={<ClampTextInlineDemo />}>

```tsx
import { ClampText, Text } from '@viraui/react';

<Text render={<p />} size="s">
  Assigned to{' '}
  <ClampText inline title="Amelia Chen · Staff engineer, Platform reliability">
    Amelia Chen · Staff engineer, Platform reliability
  </ClampText>{' '}
  until Friday.
</Text>
```

</Example>
