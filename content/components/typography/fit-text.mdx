---
title: FitText
description: Container-filling display type — scales font size to the available width with an optional max cap.
---

FitText shrinks or grows headline copy to fill its container width. Drop it inside a hero band, stat callout, or narrow sidebar where a fixed [Title](/components/typography/title) size would either overflow or leave dead space.

A hidden reference layer plus CSS container sizing scale the display copy to the parent width. `maxFontSize` caps how large the fit may grow — without it, short strings in wide containers can become enormous. Wrap [Title](/components/typography/title) or [Text](/components/typography/text) as children; the FitText root is a `div`, so pair heading semantics on the inner Title when the line belongs in the document outline.

Give the parent a defined width. Flex children need `min-width: 0` or an explicit width constraint, or the fit cannot resolve. For ordinary paragraphs, stay on [Text](/components/typography/text) with foundation fluid sizing instead.

---

## When to use

- KPI numbers, short hero words, or labels that must fill a known band width
- Sidebars and tiles where a fixed Title step would overflow or look sparse
- Display lines that need a maximum size cap via `maxFontSize`

## When not to use

- Normal body or helper paragraphs → [Text](/components/typography/text)
- Headings with a fixed typescale step and semantic tag → [Title](/components/typography/title)
- Truncation to a row count instead of scaling → [ClampText](/components/typography/clamp-text)

## Common examples

### Resize the frame

Drag the sandbox edge. The title fills the available width and scales with the frame — that is FitText’s job. No `maxFontSize` here on purpose: short words grow huge in a wide frame.

<Example preview={<FitTextResizeDemo />}>

```tsx
import { FitText, Title } from '@viraui/react';

<FitText>
  <Title render={<h2 />} size="display">
    North
  </Title>
</FitText>
```

</Example>

### Cap the growth

Same KPI fill, but `maxFontSize` stops the digit from outgrowing the layout when the frame is wide. Drag the sandbox to compare.

<Example preview={<FitTextStatDemo />}>

```tsx
import { FitText, Title } from '@viraui/react';

<FitText maxFontSize="4.5rem">
  <Title render={<h2 />} size="display">
    12.4
  </Title>
</FitText>
```

</Example>
