title: Shimmer
description: Moving highlight sweep across text — duration, spread, and angle for decorative motion.
---

Shimmer wraps inline copy in a sweep highlight across the glyphs. Reach for it when the string is already known but should feel in motion — loading placeholders, emphasis lines, or “generating” states while an agent streams.

Duration, spread, and angle tune the sweep. By default the highlight lightens `currentColor`, so host the string in muted [Text](/components/typography/text) (`tone="muted"`) or muted [Title](/components/typography/title) (`color="var(--global-muted)"`). Pure white or near-white `currentColor` leaves no room for that boost — the sweep disappears even though the glyphs stay readable. Pass `highlightColor` when you need a deliberate peak that is not a lightness step from the host.

Because the effect is decorative, pair Shimmer with visible status copy or an `aria-busy` region when it marks a loading state — the sweep alone does not explain what is loading.

Respect reduced motion: swap to static muted Text when motion would distract. Prefer [Skeleton](/components/loading/skeleton) when the content shape is unknown and you need a block placeholder instead of animated known copy.

---

## When to use

- Known status strings that should feel active while work is in progress
- Short emphasis lines where a gradient sweep reads as “live”
- Inline labels next to streaming or generating UI
- Muted host color (or an explicit `highlightColor`) so the sweep stays visible on dark surfaces

## When not to use

- Unknown layout placeholders before content arrives → [Skeleton](/components/loading/skeleton)
- Ordinary static body or heading copy → [Text](/components/typography/text) / [Title](/components/typography/title)
- Default white foreground as the only color with no `highlightColor` — the lightness boost has nowhere to go
- Nested inside [ClampText](/components/typography/clamp-text) unless you accept the clip interacting with the moving gradient

## Common examples

### Streaming status label

A single-line status label with shimmer while an agent response streams. Keep the shimmering line on muted Text, add a static muted explanation beside or below it, then replace with normal answer text when content arrives.

<Example preview={<ShimmerStatusDemo />}>

```tsx
import { Shimmer, Stack, Surface, Text } from '@viraui/react';

<Surface
  aria-busy="true"
  aria-label="Assistant is summarizing"
  border="all"
  radius="l"
  role="region"
  hPadding="m"
  vPadding="m"
>
  <Stack rowGap="m">
    <Text tone="muted">
      <Shimmer>Summarizing your request…</Shimmer>
    </Text>
    <Text size="s" tone="muted">
      This usually takes a few seconds. You can keep editing the prompt.
    </Text>
  </Stack>
</Surface>
```

</Example>

### Shimmer in a heading

Wrap Shimmer in a muted Title when the loading string should occupy heading space. Mark the surrounding region busy; leave Shimmer readable.

<Example preview={<ShimmerTitleDemo />}>

```tsx
import { Shimmer, Stack, Text, Title } from '@viraui/react';

<Stack
  aria-busy="true"
  aria-label="Generating weekly report"
  role="region"
  rowGap="s"
>
  <Title color="var(--global-muted)" render={<h2 />} size="3">
    <Shimmer>Generating weekly report…</Shimmer>
  </Title>
  <Text size="s" tone="muted">
    The heading stays in place so the layout does not jump when the real title
    arrives.
  </Text>
</Stack>
```

</Example>
