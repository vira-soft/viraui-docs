---
title: Shimmer
description: Moving highlight sweep across text — duration, spread, and angle for decorative motion.
---

Shimmer wraps inline copy in a sweep highlight across the glyphs. Reach for it when the string is already known but should feel in motion — loading placeholders, emphasis lines, or “generating” states while an agent streams.

Duration, spread, and angle tune the sweep; `highlightColor` overrides the default lightness boost derived from `currentColor`. Because the effect is decorative, pair Shimmer with visible status copy or an `aria-busy` region when it marks a loading state — the sweep alone does not explain what is loading.

Respect reduced motion: swap to static muted [Text](/components/typography/text) when motion would distract. Prefer [Skeleton](/components/loading/skeleton) when the content shape is unknown and you need a block placeholder instead of animated known copy.

---

## When to use

- Known status strings that should feel active while work is in progress
- Short emphasis lines where a gradient sweep reads as “live”
- Inline labels next to streaming or generating UI

## When not to use

- Unknown layout placeholders before content arrives → [Skeleton](/components/loading/skeleton)
- Ordinary static body or heading copy → [Text](/components/typography/text) / [Title](/components/typography/title)
- Nested inside [ClampText](/components/typography/clamp-text) unless you accept the clip interacting with the moving gradient

## Common examples

### Streaming status label

A single-line status label with shimmer while an agent response streams. Keep a static muted explanation beside or below it, then replace with normal answer text when content arrives.

<Example preview={<ShimmerStatusDemo />}>

```tsx
import { Shimmer, Stack, Surface, Text } from '@viraui/react';

<Surface
  aria-busy="true"
  aria-label="Assistant is summarizing"
  border="all"
  radius="l"
  role="region"
  hPadding="m"
  vPadding="m"
>
  <Stack rowGap="2xs">
    <Text>
      <Shimmer>Summarizing your request…</Shimmer>
    </Text>
    <Text />
  </Stack>
</Surface>
```

</Example>

### Shimmer in a heading

Wrap Shimmer in [Title](/components/typography/title) when the loading string should occupy heading space. Mark the surrounding region busy; leave Shimmer readable.

<Example preview={<ShimmerTitleDemo />}>

```tsx
import { Shimmer, Stack, Text, Title } from '@viraui/react';

<Stack aria-busy="true" aria-label="Generating weekly report" role="region">
  <Title render={<h2 />} size="3">
    <Shimmer>Generating weekly report…</Shimmer>
  </Title>
  <Text />
</Stack>
```

</Example>
