title: Text
description: Body-scale copy — size, tone, weight, line height, trim, and render for semantic inline or block roots.
---

Text is the default running-copy primitive on the body typescale. `size` steps from `xs` through `4xl`; `tone` maps to semantic color roles (`muted`, `interactive`, status highlights) without hand-picking hex values. `weight`, `lineHeight`, `align`, `maxWidth`, and `whiteSpace` cover most layout needs; `balanced` enables nicer wrapping on short marketing lines. `family` switches between body and mono — reach for mono on code snippets and data, not headings. Pass `fluid` for viewport clamp between size steps; omit it (default) to lock each step at its `--font-scale-body-*` token. Theme `--effect-fluid-typography: initial` still locks all Text globally (`xs` stays fixed either way).

Default root is `span`. Use `render` when the copy needs a different element (`p`, `label`, `code`) while keeping Text styling. `trim` applies `text-box` edge trimming when the browser supports it so stacked lines sit tighter in flex layouts. Literal `color` is an escape hatch — prefer `tone` so theme changes stay centralized. For headings, use [Title](/components/typography/title) instead of bumping Text `size`. For the fluid gate details, see [Typography](/foundation/typography).
