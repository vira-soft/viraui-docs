---
title: Text
description: Body-scale copy — size, tone, weight, and layout for semantic inline or block roots.
---

Text is the default running-copy primitive on the body typescale. Reach for it for helper lines, descriptions, labels, and any sentence that is not a heading.

`size` and `tone` cover most look choices; `weight`, `lineHeight`, `tracking`, `align`, `maxWidth`, and `whiteSpace` handle layout. Default root is `span` — pass `render` when the copy needs a `p`, `label`, `code`, or other element while keeping Text styling. Prefer `tone` over a literal `color` so theme changes stay centralized. Use `tracking` instead of CSS `letter-spacing` on the same Text root.

For headings, use [Title](/components/typography/title) instead of bumping Text `size`. Fluid viewport clamp and the foundation typography gate are covered on [Typography](/foundation/typography).

---

## When to use

- Supporting copy under a section or control
- Body paragraphs, captions, and inline labels that share the body scale
- Mono snippets or data lines via `family` when the line is not a heading
- Semantic roots (`p`, `label`, `code`) that still need Text styling

## When not to use

- Page or section headings → [Title](/components/typography/title)
- Copy that must fill a tile width → [FitText](/components/typography/fit-text)
- Overflow that should ellipsize to a fixed row count → [ClampText](/components/typography/clamp-text)
- Long-form heading and block rhythm → [Prose](/components/typography/prose)

## Common examples

### Muted helper line

Muted supporting copy under a section heading is the baseline Text pattern. Keep the line on the body scale; do not fake a heading with oversized Text.

<Example preview={<TextMutedHelperDemo />}>

```tsx
import { Stack, Text, Title } from '@viraui/react';

<Stack rowGap="2xs">
  <Title />
  <Text maxWidth="36ch" size="s" tone="muted">
    Choose which product emails you still want. You can change this later.
  </Text>
</Stack>
```

</Example>

### Semantic block root

Default Text is a `span`. Pass `render` when the outline or form needs a `p` or `label` while the same size, tone, and weight still apply.

<Example preview={<TextSemanticRootDemo />}>

```tsx
import { Stack, Text } from '@viraui/react';

<Stack rowGap="m">
  <Text render={<p />}>
    Workspace members can invite teammates, manage billing, and publish shared
    libraries.
  </Text>
  <Text render={<label />} size="s" weight="semibold">
    Workspace name
  </Text>
</Stack>
```

</Example>

### Nested tones

Nest Text to retone a phrase without restating `size`. Inner copies inherit the outer body size unless you set one.

<Example preview={<TextNestedTonesDemo />}>

```tsx
import { Text } from '@viraui/react';

<Text size="l" tone="muted">
  Deploy finished with{' '}
  <Text tone="danger">
    3 failing checks
  </Text>{' '}
  and{' '}
  <Text tone="positive">
    18 passing
  </Text>
  . Review the failed jobs before you merge.
</Text>
```

</Example>

### Line height

`lineHeight` picks a foundation leading token (`none` | `xs` | `s` | `m` | `l`). Root Text defaults to `m`; omit it on nested Text so leading inherits from the outer copy.

<Example preview={<TextLineHeightDemo />}>

```tsx
import { Text } from '@viraui/react';

<Text
  align="center"
  lineHeight="l"
  maxWidth="36ch"
  render={<p />}
  size="s"
>
  Northwind Analytics keeps shared dashboards, scheduled exports, and
  access reviews in one workspace so regional teams can publish without
  duplicating reports.
</Text>
```

</Example>

### Letter spacing

Set letter-spacing with `tracking` — a CSS length such as `0.12em`. Prefer this prop over CSS `letter-spacing` on the same Text root. Pair wide tracking with `transform="uppercase"` for section labels.

<Example preview={<TextTrackingDemo />}>

```tsx
import { Text } from '@viraui/react';

<Text
  align="center"
  size="s"
  tracking="0.12em"
  transform="uppercase"
  weight="semibold"
>
  Field notes
</Text>
```

</Example>
