Title renders heading and display presets from the theme typescale. `size` controls appearance (`display`, `1`–`6`); `render` chooses the actual element — default root is `span`, so outline-bearing headings need an explicit `render={<h2 />}` (or the level the page structure requires). Visual size and semantic level stay independent on purpose: a quiet `h1` with `size="4"` is valid when SEO needs one page title but the layout calls for a smaller look.

`lineHeight`, `align`, `maxWidth`, `balanced`, and `trim` mirror [Text](/components/typography/text) layout controls at heading densities. `weight` accepts a numeric override when a preset needs a heavier or lighter draw without changing `size`. Literal `color` bypasses theme heading color — use sparingly on marketing hero lines. Fluid viewport clamp is on by default; pass `fluid={false}` to lock one instance, or set `--effect-fluid-typography: initial` on the theme root to lock every preset at its `--font-scale-display` / `--font-scale-h*` token. Avoid hand-written media queries for ordinary heading steps.
