Title is the heading and display primitive on the theme typescale. Use it for heroes, section titles, and any line that belongs in the document outline.

`size` controls appearance (`display`, `1`–`6`); `render` chooses the actual element. Default root is `span`, so outline-bearing headings need an explicit `render={<h2 />}` (or the level the page structure requires). Visual size and semantic level stay independent on purpose: a quiet `h1` with a smaller `size` is valid when SEO needs one page title but the layout calls for a quieter look.

Layout controls (`lineHeight`, `align`, `maxWidth`, `balanced`, `trim`) mirror [Text](/components/typography/text) at heading densities. Fluid viewport clamp is on by default for ordinary heading steps — see [Typography](/foundation/typography) for the foundation gate.

---

## When to use

- Page heroes and section or subsection headings
- Display lines that still need a semantic heading tag
- Balanced wrapping on short marketing titles

## When not to use

- Body, helper, or caption copy → [Text](/components/typography/text)
- A line that must grow or shrink to fill a band → [FitText](/components/typography/fit-text)
- Truncating a title inside a fixed card chrome → wrap with [ClampText](/components/typography/clamp-text)

## Common examples

### Semantic page title

A page hero with a visual size preset and `render={<h1 />}` plus balanced wrapping. Keep supporting sentences on [Text](/components/typography/text) underneath.

<Example preview={<TitleSemanticPageDemo />}>

```tsx
import { Stack, Text, Title } from '@viraui/react';

<Stack rowGap="s">
  <Title balanced render={<h1 />} size="1">
    Ship the next release without the guesswork
  </Title>
  <Text />
</Stack>
```

</Example>

### Visual size vs semantic level

The document outline and the visual preset do not have to match. A quieter `size` on `h1` still marks the page title when the layout should not shout.

<Example preview={<TitleVisualVsSemanticDemo />}>

```tsx
import { Stack, Text, Title } from '@viraui/react';

<Stack rowGap="2xs">
  <Title render={<h1 />} size="5">
    Notifications
  </Title>
  <Text />
</Stack>
```

</Example>
