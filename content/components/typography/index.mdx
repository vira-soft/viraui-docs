Typography components carry copy with foundation tokens instead of one-off CSS. [Text](/components/typography/text) owns the body scale and semantic tones; [Title](/components/typography/title) owns heading presets with `render` for real document outline tags. [ClampText](/components/typography/clamp-text) and [FitText](/components/typography/fit-text) handle truncation and container-filling display type; [Shimmer](/components/typography/shimmer) adds a moving highlight sweep for loading or emphasis lines. Theme typescale detail lives in [Typography foundation](/foundation/typography) — these pages focus on compose patterns.
