Navigation components here organize content that shares one screen without a full route change. [Tabs](/components/navigation/tabs) keeps a `tablist` of triggers aligned to `tabpanel` regions — keyboard selection, optional scroll when labels overflow, and a sliding indicator track which tab is active. Use tabs when panels are peers (settings sections, detail facets); use route-level navigation when each view needs its own URL and lifecycle.

- [Tabs](/components/navigation/tabs)
