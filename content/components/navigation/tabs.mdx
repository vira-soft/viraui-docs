Tabs keep related views on one screen. Compose a `Tabs.List` of `Tabs.Tab` triggers with matching `Tabs.Panel` children inside `Tabs.Viewport`. The root owns selection — `defaultValue` when the compound owns it, or `value` plus `onValueChange` when the URL, a deep link, or another control drives the active tab.

Each tab’s `value` pairs with exactly one panel of the same `value`. Only the selected panel stays mounted while the indicator moves under the active trigger. Long label sets scroll horizontally inside the list; that overflow is expected, not a layout bug.

`listAlignment` aligns the segment chrome through the same stack contract as [Stack](/components/layout/stack) — prefer `center` for a compact list; use `stretch` when equal-width tabs should fill the row. Set `activateOnFocus={false}` on `Tabs.List` when keyboard focus should move without changing selection until click or Enter. Labels accept `addon` slots for icons or [Chip](/components/widgets/chip) badges; disabled tabs ignore activation.

---

## When to use

- Peer sections of the same screen (profile, billing, goals)
- In-page wayfinding where content swaps without a route change
- Selection that should sync to search params, a deep link, or another control

## When not to use

- Expand/collapse FAQs or stacked disclosures → [Accordion](/components/layout/accordion)
- Ordered multi-step flows (continue / next / back) → a dedicated stepper, not Tabs
- Primary app routes or top-level destinations → links and the router
- Commands from a trigger → [Menu](/components/overlays/menu)

---

## Related

- [Accordion](/components/layout/accordion) — expand/collapse sections on the same page

## Common examples

### Tabbed panels

A three-tab block with paired list triggers and viewport panels is the default in-page navigation pattern. Seed the active tab with `defaultValue`, and keep the list compact with `listAlignment="center"`.

<Example preview={<TabsPanelsDemo />}>

```tsx
import { Tabs, Text, Title } from '@viraui/react';

<Tabs defaultValue="general" listAlignment="center">
  <Tabs.List>
    <Tabs.Tab value="general">General</Tabs.Tab>
    <Tabs.Tab value="billing">Billing</Tabs.Tab>
    <Tabs.Tab value="goals">Goals</Tabs.Tab>
  </Tabs.List>
  <Tabs.Viewport>
    <Tabs.Panel value="general">
      <Title />
      <Text />
    </Tabs.Panel>
    <Tabs.Panel value="billing">
      <Title />
      <Text />
    </Tabs.Panel>
    <Tabs.Panel value="goals">
      <Title />
      <Text />
    </Tabs.Panel>
  </Tabs.Viewport>
</Tabs>
```

</Example>

### Tab addons

Put icons or Chip badges in `addon` without changing the accessible name — visible tab text stays the label. Use `addonPosition="end"` for trailing badges.

<Example preview={<TabsAddonsDemo />}>

```tsx
import { GearSix, Target } from '@phosphor-icons/react';
import { Chip, Tabs, Text, Title } from '@viraui/react';

<Tabs defaultValue="general" listAlignment="center">
  <Tabs.List>
    <Tabs.Tab addon={<GearSix />} value="general">
      General
    </Tabs.Tab>
    <Tabs.Tab
      addon={<Chip variant="green">New</Chip>}
      addonPosition="end"
      value="billing"
    >
      Billing
    </Tabs.Tab>
    <Tabs.Tab addon={<Target />} value="goals">
      Goals
    </Tabs.Tab>
  </Tabs.List>
  <Tabs.Viewport>
    <Tabs.Panel value="general">
      <Title />
      <Text />
    </Tabs.Panel>
    <Tabs.Panel value="billing">
      <Title />
      <Text />
    </Tabs.Panel>
    <Tabs.Panel value="goals">
      <Title />
      <Text />
    </Tabs.Panel>
  </Tabs.Viewport>
</Tabs>
```

</Example>

### Stretch list

`listAlignment="stretch"` fills the list chrome so equal-width tabs sit edge to edge — useful for two-option choosers.

<Example preview={<TabsStretchDemo />}>

```tsx
import { Surface, Tabs, Text, Title } from '@viraui/react';

<Surface border="all" color={1} hPadding="m" overflow="hidden" radius="m" vPadding="m">
  <Tabs defaultValue="local" listAlignment="stretch">
    <Tabs.List>
      <Tabs.Tab value="codespaces">Codespaces</Tabs.Tab>
      <Tabs.Tab value="local">Local</Tabs.Tab>
    </Tabs.List>
    <Tabs.Viewport>
      <Tabs.Panel value="codespaces">
        <Title />
        <Text />
      </Tabs.Panel>
      <Tabs.Panel value="local">
        <Title />
        <Text />
      </Tabs.Panel>
    </Tabs.Viewport>
  </Tabs>
</Surface>
```

</Example>

### Scrollable overflow

When labels exceed the list width, the tab row scrolls horizontally. Constrain the shell so overflow is visible; do not force wrap or shrink labels to fit.

<Example preview={<TabsScrollableDemo />}>

```tsx
import { Stack, Tabs, Text } from '@viraui/react';

const items = [
  { label: 'Overview', value: 'overview' },
  { label: 'Analytics', value: 'analytics' },
  { label: 'Reports', value: 'reports' },
  { label: 'Team members', value: 'team' },
  { label: 'Billing', value: 'billing' },
  { label: 'Security', value: 'security' },
  { label: 'Notifications', value: 'notifications' },
  { label: 'API keys', value: 'api-keys' },
  { label: 'Webhooks', value: 'webhooks' },
  { label: 'Integrations hub', value: 'integrations' },
];

<Stack maxWidth="20rem">
  <Tabs defaultValue="overview" listAlignment="center">
    <Tabs.List>
      {items.map((item) => (
        <Tabs.Tab key={item.value} value={item.value}>
          {item.label}
        </Tabs.Tab>
      ))}
    </Tabs.List>
    <Tabs.Viewport>
      {items.map((item) => (
        <Tabs.Panel key={item.value} value={item.value}>
          <Text />
        </Tabs.Panel>
      ))}
    </Tabs.Viewport>
  </Tabs>
</Stack>
```

</Example>

### Programmatic selection

Drive selection with `value` and `onValueChange` when a panel action, URL param, or deep link owns the active tab. Call the same setter from a Button inside a panel to jump to a peer section — for example Profile → Billing — not as a step sequence.

<Example preview={<TabsProgrammaticDemo />}>

```tsx
import * as React from 'react';
import { Button, Tabs, Text, Title } from '@viraui/react';

const [tab, setTab] = React.useState('profile');

<Tabs
  value={tab}
  listAlignment="center"
  onValueChange={(next) => setTab(String(next))}
>
  <Tabs.List>
    <Tabs.Tab value="profile">Profile</Tabs.Tab>
    <Tabs.Tab value="billing">Billing</Tabs.Tab>
    <Tabs.Tab value="security">Security</Tabs.Tab>
  </Tabs.List>
  <Tabs.Viewport>
    <Tabs.Panel value="profile">
      <Title />
      <Text />
      <Button
        onClick={() => setTab('billing')}
        type="button"
        variant="secondary"
      >
        View billing plan
      </Button>
    </Tabs.Panel>
    <Tabs.Panel value="billing">
      <Title />
      <Text />
      <Button
        onClick={() => setTab('profile')}
        type="button"
        variant="secondary"
      />
    </Tabs.Panel>
    <Tabs.Panel value="security">
      <Title />
      <Text />
    </Tabs.Panel>
  </Tabs.Viewport>
</Tabs>
```

</Example>

Set `activateOnFocus={false}` on `Tabs.List` when arrow-key focus should not change the selected panel until the user activates with click, Enter, or Space.
