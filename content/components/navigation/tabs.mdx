Tabs keep related views on one screen. Compose a `Tabs.List` of `Tabs.Tab` triggers with matching `Tabs.Panel` children inside `Tabs.Viewport`. The root owns selection — `defaultValue` when the compound owns it, or `value` plus `onValueChange` when the URL or another control drives the active tab.

Each tab’s `value` pairs with exactly one panel of the same `value`. Only the selected panel stays mounted while the indicator moves under the active trigger. Long label sets scroll horizontally inside the list; that overflow is expected, not a layout bug.

`listAlignment` aligns the tab row through the same stack contract as [Stack](/components/layout/stack). Set `activateOnFocus={false}` on `Tabs.List` when keyboard focus should move without changing selection until click. Labels accept `addon` slots for icons or [Chip](/components/widgets/chip) badges; disabled tabs ignore activation.

## When to use

- Peer sections of the same screen (profile, billing, goals)
- In-page wayfinding where content swaps without a route change
- Selection that should sync to search params or another control

## When not to use

- Expand/collapse FAQs or stacked disclosures → [Accordion](/components/layout/accordion)
- Primary app routes or top-level destinations → links and the router
- Commands from a trigger → [Menu](/components/overlays/menu)

## Related

- [Accordion](/components/layout/accordion) — expand/collapse sections on the same page
- [Menu](/components/overlays/menu) — command lists anchored to a trigger
- [Chip](/components/widgets/chip) — badges in tab addons

## Common examples

### Tabbed panels

A three-tab block with paired list triggers and viewport panels is the default in-page navigation pattern. Seed the active tab with `defaultValue` so the first panel mounts on load.

<PreviewSlot label="Tabs preview" />

```tsx
import { Stack, Tabs, Text, Textfield, Title } from '@viraui/react';

<Tabs defaultValue="general">
  <Tabs.List>
    <Tabs.Tab value="general">General</Tabs.Tab>
    <Tabs.Tab value="billing">Billing</Tabs.Tab>
    <Tabs.Tab value="goals">Goals</Tabs.Tab>
  </Tabs.List>
  <Tabs.Viewport>
    <Tabs.Panel value="general">
      <Stack rowGap="m">
        <Title />
        <Text />
        <Textfield label="Workspace name" />
      </Stack>
    </Tabs.Panel>
    <Tabs.Panel value="billing">
      <Text />
    </Tabs.Panel>
    <Tabs.Panel value="goals">
      <Text />
    </Tabs.Panel>
  </Tabs.Viewport>
</Tabs>
```
