title: Tabs
description: Tab list and panels in one compound — animated indicator, controlled value, scrollable overflow.
---

Tabs splits wayfinding from content: `Tabs.List` holds `Tabs.Tab` triggers, and `Tabs.Viewport` mounts one `Tabs.Panel` per `value`. The root owns selection — `defaultValue` for uncontrolled usage, `value` plus `onValueChange` when another control must drive the active tab. Each tab’s `value` string pairs with exactly one panel of the same `value`; only the selected panel stays mounted in the viewport while the indicator animates under the active trigger.

`listAlignment` on the root aligns the tab row (`start`, `center`, …) through the same stack contract as [Stack](/components/layout/stack). Long label sets scroll horizontally inside the list — overflow is expected, not a layout bug. Set `activateOnFocus={false}` on `Tabs.List` when keyboard focus should move across tabs without changing selection until click. Disabled tabs carry `disabled` on `Tabs.Tab` and ignore activation. Tab labels accept `addon` slots — icons or [Chip](/components/widgets/chip) badges — with `addonPosition` when the addon trails the text. Functional motion on the indicator follows theme [motion](/foundation/motion) tokens.

## Common examples

A three-tab settings block with general, billing, and goals panels is the canonical layout.


```tsx
import { Stack, Tabs, Text, Textfield, Title } from '@viraui/react';

<Tabs defaultValue="general">
  <Tabs.List>
    <Tabs.Tab value="general">General</Tabs.Tab>
    <Tabs.Tab value="billing">Billing</Tabs.Tab>
    <Tabs.Tab value="goals">Goals</Tabs.Tab>
  </Tabs.List>
  <Tabs.Viewport>
    <Tabs.Panel value="general">
      <Stack rowGap="m">
        <Title size="3" render={<h3 />}>
          Profile & workspace
        </Title>
        <Text tone="muted">Manage how your team appears across projects.</Text>
        <Textfield label="Workspace name" defaultValue="Northwind Labs" />
      </Stack>
    </Tabs.Panel>
    <Tabs.Panel value="billing">
      <Text>Billing panel content</Text>
    </Tabs.Panel>
    <Tabs.Panel value="goals">
      <Text>Goals panel content</Text>
    </Tabs.Panel>
  </Tabs.Viewport>
</Tabs>
```
