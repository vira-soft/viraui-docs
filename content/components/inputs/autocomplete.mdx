Autocomplete combines a text input with a filterable popup. Type to narrow `items`, pick a row, or keep free-form text when the list is only a suggestion.

Field label, description, error copy, and `startAddon` / `endAddon` chrome match [Textfield](/components/inputs/textfield); options render as `Autocomplete.Item` rows on an elevated `Surface` like [Select](/components/inputs/select). Pass list content as a render function over `items`, or compose `Autocomplete.Group` with `Autocomplete.Collection` for sectioned results. Keep root `status` mounted and update its children when async messaging changes; clear or omit `empty` while pending so no-match copy does not flash over a spinner. Fill a form column from a parent [Stack](/components/layout/stack) with `fullWidth` / `expandChildren` — Autocomplete has no `fullWidth` prop of its own.

---

## When to use

- Large lists where typing to filter is easier than scanning a closed dropdown
- Values that may stay free-form when nothing in the list matches (tags, categories)
- Async search with a mounted status slot while results load

## When not to use

- A fixed short list with no typing → [Select](/components/inputs/select)
- Open text with no suggestion list → [Textfield](/components/inputs/textfield)
- A short, always-visible single choice → [Radio](/components/inputs/radio)

---

## Related

- [Select](/components/inputs/select) — closed-choice popup without filtering
- [Textfield](/components/inputs/textfield) — single-line text without a suggestion list
- [Radio](/components/inputs/radio) — visible mutually exclusive options

## Common examples

### Filterable options

A labeled Autocomplete with search chrome and item addons is the baseline suggest pattern. `itemToStringValue` maps each object to the string written into the input when a row is chosen. When that string matches an item, `endAddon` can mirror a related preview (here an Avatar).

<Example preview={<AutocompleteReviewerDemo />}>

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react';
import { Autocomplete, Avatar, Stack } from '@viraui/react';

const reviewers = [
  {
    id: 'r1',
    label: 'Sarah Chen',
    role: 'Product Design',
    fallback: 'SC',
    src: 'https://mockmind-api.uifaces.co/content/human/80.jpg',
  },
  {
    id: 'r2',
    label: 'Marcus Reed',
    role: 'Engineering',
    fallback: 'MR',
    src: 'https://mockmind-api.uifaces.co/content/human/219.jpg',
  },
];

const [value, setValue] = useState('');
const selected = reviewers.find((person) => person.label === value);

<Autocomplete
  label="Assign reviewer"
  description="Pick a teammate who can approve this payout batch."
  empty="No teammates match that name."
  placeholder="Search by name…"
  items={reviewers}
  itemToStringValue={(person) => person.label}
  value={value}
  onValueChange={setValue}
  startAddon={<MagnifyingGlass aria-hidden size={16} />}
  endAddon={
    selected ? (
      <Stack hPadding={[0, 'xs']}>
        <Avatar
          alt={selected.label}
          fallback={selected.fallback}
          size="xs"
          src={selected.src}
        />
      </Stack>
    ) : undefined
  }
>
  {(person) => (
    <Autocomplete.Item
      key={person.id}
      addon={
        <Avatar
          alt={person.label}
          fallback={person.fallback}
          size="s"
          src={person.src}
        />
      }
      value={person}
    >
      {`${person.label} · ${person.role}`}
    </Autocomplete.Item>
  )}
</Autocomplete>
```

</Example>

Buttons inside `endAddon` must use `type="button"` so they do not submit a parent form.

### Free-form value

Flat items still allow free-form text — the list suggests options while the input can keep a custom phrase. Prefer this over Select when the value does not have to be one of the options.

<Example preview={<AutocompleteCategoryDemo />}>

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react';
import { Autocomplete } from '@viraui/react';

const expenseCategories = [
  { id: 'c1', label: 'SaaS subscriptions' },
  { id: 'c2', label: 'Travel' },
  { id: 'c3', label: 'Contractors' },
];

<Autocomplete
  label="Expense category"
  description="Suggest a ledger category — free-form text stays allowed."
  empty="No category match. Keep typing to create a custom label."
  placeholder="SaaS, travel, contractors…"
  items={expenseCategories}
  itemToStringValue={(category) => category.label}
  startAddon={<MagnifyingGlass aria-hidden size={16} />}
>
  {(category) => (
    <Autocomplete.Item key={category.id} value={category}>
      {category.label}
    </Autocomplete.Item>
  )}
</Autocomplete>
```

</Example>

### Grouped options

Grouped `items` pair with `Autocomplete.Group` and `Autocomplete.Collection` so each section keeps its own heading and nested rows.

<Example preview={<AutocompleteGroupedDemo />}>

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react';
import { Autocomplete } from '@viraui/react';

const transferDesks = [
  {
    value: 'Europe',
    items: [
      { id: 'd1', label: 'Paris', hours: '09:00–18:00 CET' },
      { id: 'd2', label: 'Berlin', hours: '08:00–17:00 CET' },
    ],
  },
  {
    value: 'Americas',
    items: [{ id: 'd3', label: 'Austin', hours: '08:00–17:00 CT' }],
  },
];

<Autocomplete
  label="Transfer desk"
  description="Route an urgent payout to the desk covering that region."
  empty="No transfer desk matches."
  placeholder="Paris, Berlin, Austin…"
  items={transferDesks}
  itemToStringValue={(desk) => desk.label}
  startAddon={<MagnifyingGlass aria-hidden size={16} />}
>
  {(group) => (
    <Autocomplete.Group key={group.value} items={group.items} label={group.value}>
      <Autocomplete.Collection>
        {(desk) => (
          <Autocomplete.Item key={desk.id} value={desk}>
            {`${desk.label} · ${desk.hours}`}
          </Autocomplete.Item>
        )}
      </Autocomplete.Collection>
    </Autocomplete.Group>
  )}
</Autocomplete>
```

</Example>

### Async status

When results load outside the control, set `filter={null}` and drive `items` from your fetch. Keep root `status` mounted — swap Spinner and muted copy inside it while the request runs. Clear or omit `empty` while pending so the no-match copy does not flash over the spinner.

<Example preview={<AutocompleteAsyncDemo />}>

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react';
import { Autocomplete, Spinner, Stack, Text } from '@viraui/react';

const empty = pending ? undefined : 'No articles for that query.';

<Autocomplete
  label="Search help center"
  description="Async docs search."
  empty={empty}
  filter={null}
  items={results}
  itemToStringValue={(article) => article.title}
  placeholder="Wire limits, SEPA, tax forms…"
  startAddon={<MagnifyingGlass aria-hidden size={16} />}
  status={
    pending ? (
      <Stack columnGap="s" direction="row" vAlign="center">
        <Spinner aria-hidden size="s" />
        <Text size="xs" tone="muted">
          Searching help center…
        </Text>
      </Stack>
    ) : null
  }
>
  {(article) => (
    <Autocomplete.Item key={article.id} value={article}>
      {`${article.title} · ${article.section}`}
    </Autocomplete.Item>
  )}
</Autocomplete>
```

</Example>

In iframe previews, shadow roots, or custom overlay hosts, pass `container` on Autocomplete so the popup portals into that document instead of the default body.
