---

`Select` is a closed-choice control — the trigger shows the current value and opens a popup list of `Select.Option` rows rendered on a `Surface` with `Elevator` shadow so the menu reads above page content. Field label, description, and error copy follow the shared Vira input pattern; value, disabled state, and change handlers pass through Base UI `Select`. Compose options inline or inside `Select.Group` when sections need headings; use `Select.Separator` between groups. For free-text filtering over a long list, prefer [`Autocomplete`](/components/inputs/autocomplete) instead.
