---
title: Slider
description: Range input for numeric values — single thumb or dual-thumb range selection.
---

`Slider` exposes a draggable thumb on a track for choosing one number or a min–max range between `min`, `max`, and `step`. Label, description, and error copy follow the shared field pattern; orientation, disabled state, and value change handlers pass through Base UI `Slider`. Pass a two-element `value` array for range mode — the component detects range layout automatically. Use `Slider` when the valid interval is continuous and the exact number matters less than position on a scale; use `Select` or `Radio` for discrete named choices.
