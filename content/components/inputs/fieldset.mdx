Fieldset gives a cluster of controls a visible legend plus optional group-level description and error copy. Use it when [Radio](/components/inputs/radio) or [Checkbox](/components/inputs/checkbox) options need a shared group name, or when several labeled fields share one section heading.

Pass `render` to merge the fieldset root with `RadioGroup` or `CheckboxGroup` so the group and legend stay one accessible unit. Group validation and `name` still live on `Field.Root` above the fieldset; individual options keep their own labels. Border and card chrome belong on [Surface](/components/layout/surface), not on Fieldset.

---

## When to use

- A RadioGroup or CheckboxGroup that needs a legend, shared description, or group error
- Several related Textfields under one section name (billing details, address block)

## When not to use

- A lone field with its own label (no shared legend)
- Card border, radius, or fill → wrap with [Surface](/components/layout/surface)
- Immediate settings toggles that do not need a group legend → [Switch](/components/inputs/switch) rows alone

## Common examples

### Labeled section

A Surface card with a Fieldset legend over related Textfields is the baseline field grouping — no `render` merge when children already own their labels.

<Example preview={<FieldsetBillingDemo />}>

```tsx
import { Fieldset, Separator, Stack, Surface, Textfield } from '@viraui/react';

<Surface border="all" overflow="hidden" radius="l" hPadding="l" vPadding="l">
  <Fieldset label="Billing details">
    <Stack rowGap="m">
      <Separator />
      <Textfield name="company" label="Company" />
      <Textfield name="taxId" label="Tax ID" />
    </Stack>
  </Fieldset>
</Surface>
```

</Example>

### Nested RadioGroup

Choice groups that need a shared legend or description merge `RadioGroup` through `render` under `Field.Root`. Each option keeps its own `label` / `description`.

<Example preview={<FieldsetDeliveryDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Fieldset, Radio, RadioGroup, Separator, Stack } from '@viraui/react';

const [value, setValue] = useState('express');

<Field.Root name="delivery">
  <Fieldset
    label="Delivery"
    description="Choose one option for this shipment."
    render={<RadioGroup value={value} onValueChange={setValue} />}
  >
    <Stack rowGap="m">
      <Separator />
      <Radio label="Standard" description="3–5 business days." value="standard" />
      <Radio label="Express" description="1–2 business days." value="express" />
      <Radio
        label="Overnight"
        description="Next business morning."
        value="overnight"
      />
    </Stack>
  </Fieldset>
</Field.Root>
```

</Example>

### Group error

Drive Fieldset `error` from `Field.Root` `invalid`. Keep `description` set — helper copy shows while valid; error replaces it when invalid. Surface owns the card chrome; highlight checked cards with `color`.

<Example preview={<FieldsetPlanErrorDemo />}>

```tsx
import { Field } from '@base-ui/react';
import {
  Checkbox,
  CheckboxGroup,
  Fieldset,
  Separator,
  Stack,
  Surface,
} from '@viraui/react';

const [value, setValue] = useState<string[]>([]);
const empty = value.length === 0;

<Field.Root dirty invalid={empty} name="plan">
  <Fieldset
    label="Plan"
    description="Pick every plan tier this workspace may trial."
    error={empty ? 'Select a plan to continue.' : undefined}
    render={<CheckboxGroup value={value} onValueChange={setValue} />}
  >
    <Stack expandChildren rowGap="s">
      <Separator />
      <Surface
        border="all"
        radius="m"
        {...(value.includes('free') ? { color: 3 } : {})}
      >
        <Checkbox
          label="Free"
          description="For getting started."
          value="free"
          hPadding="m"
          vPadding="m"
        />
      </Surface>
      <Surface
        border="all"
        radius="m"
        {...(value.includes('pro') ? { color: 3 } : {})}
      >
        <Checkbox
          label="Pro"
          description="For growing teams."
          value="pro"
          hPadding="m"
          vPadding="m"
        />
      </Surface>
    </Stack>
  </Fieldset>
</Field.Root>
```

</Example>
