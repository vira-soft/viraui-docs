Textarea is the multi-line control for notes, message bodies, bios, and other long-form values. It uses the same field layout as [Textfield](/components/inputs/textfield) for label, description, and error copy, so long answers match the rest of the form.

Pass `rows`, `placeholder`, and standard textarea attributes on the control; validation flows through Base UI `Field` the same way as single-line inputs. `fitContent` grows the control with its value; `resize` opts into a native drag handle (`vertical`, `horizontal`, or `both`) when users need more room. Width fill comes from a parent [Stack](/components/layout/stack) with `fullWidth` / `expandChildren` — Textarea has no `fullWidth` prop and no addon slots.

---

## When to use

- Values that naturally span multiple lines (feedback, release notes, comments)
- Fields that should grow with typing (`fitContent`) or offer a resize handle

## When not to use

- Single-line identifiers or short values → [Textfield](/components/inputs/textfield)
- Prefix, search glyph, or trailing action chrome → Textfield addons (Textarea has none)

## Common examples

### Message body

A labeled message with helper copy and Field validation is the baseline long-form input. Pair it with a submit button in a `Stack` — no extra Field wrapper around Textarea itself.

<Example preview={<TextareaMessageDemo />}>

```tsx
import { Button, Stack, Textarea } from '@viraui/react';

<Stack rowGap="l">
  <Textarea
    label="Message"
    description="Tell us what went wrong or what would help next time."
    name="message"
    placeholder="Describe the issue in a few sentences…"
    rows={4}
    validationMode="onChange"
    validate={(value) => {
      const trimmed = String(value ?? '').trim();
      if (!trimmed) return 'Enter a message.';
      if (trimmed.length < 12) return 'Message must be at least 12 characters.';
      return null;
    }}
  />
  <Button />
</Stack>
```

</Example>

### Fit content

`fitContent` grows the control with its value via `field-sizing: content`. Keep a small `rows` floor; the field still respects `min-block-size`. Use this when notes should expand as the user types instead of forcing a drag handle.

<Example preview={<TextareaFitContentDemo />}>

```tsx
import { Textarea } from '@viraui/react';

<Textarea
  fitContent
  defaultValue="Ship notes…"
  label="Release notes"
  description="The field grows as you add lines — no drag handle needed."
  name="release-notes"
  rows={2}
/>
```

</Example>

### Vertical resize

Combine `resize="vertical"` with `fitContent` when the field should grow with content and still offer a drag handle for extra room. Omitted `resize` keeps the handle off (`none`).

<Example preview={<TextareaResizeDemo />}>

```tsx
import { Button, Stack, Textarea } from '@viraui/react';

<Stack rowGap="l">
  <Textarea
    fitContent
    resize="vertical"
    label="Notes"
    description="Grows with the value; drag the corner when you want more room."
    name="notes"
    placeholder="Add any notes…"
    rows={3}
  />
  <Button />
</Stack>
```

</Example>
