title: Checkbox
description: Boolean option row with label and helper copy — standalone or inside CheckboxGroup.
---

`Checkbox` renders a single on/off option with Vira label and helper typography beside the control. Standalone checkboxes need an external `Field.Root` wrapper for validation, naming, and group-level error wiring; inside `CheckboxGroup`, options share the group name and selection model from Base UI. The control exposes `size` for visual scale and supports indeterminate state through Base UI pass-through props. Pair multiple related options with [`Fieldset`](/components/inputs/fieldset) when the group needs a legend and shared description.

## Common examples

A Fieldset-backed CheckboxGroup with three labeled preference rows is the default multi-select pattern.
