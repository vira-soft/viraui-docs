## Base UI

Checkbox is a single on/off option with label and helper copy beside the control. Standalone rows need an external `Field.Root` from `@base-ui/react` for naming and validation; Checkbox does not own a field root the way [Textfield](/components/inputs/textfield) does.

Related options share a selection model through `CheckboxGroup`. Add [Fieldset](/components/inputs/fieldset) with `render={<CheckboxGroup />}` only when the group needs a legend or shared description; otherwise `CheckboxGroup` may sit directly in `Field.Root`. Checked, indeterminate, disabled, and change handlers pass through Base UI; `size` scales the control and label.

## When to use

- A boolean that ships with a larger form submit (terms, save-as-default)
- Several independent options that can stay on at once (alert channels, plan tiers)
- A select-all row that needs an indeterminate state when only some children are checked

## When not to use

- The change should apply immediately as a setting → [Switch](/components/inputs/switch)
- Exactly one choice is allowed → [Radio](/components/inputs/radio)
- A long closed list in a popup → [Select](/components/inputs/select)

## Related

- [Fieldset](/components/inputs/fieldset) — legend and group helper for CheckboxGroup
- [Switch](/components/inputs/switch) — immediate on/off settings
- [Radio](/components/inputs/radio) — mutually exclusive options

## Common examples

### Labeled group

A Fieldset-backed `CheckboxGroup` with labeled preference rows is the default multi-select pattern. Each option keeps its own `label` / `description`; the group owns `value` and `onValueChange`.

<Example preview={<CheckboxPreferencesDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Checkbox, CheckboxGroup, Fieldset, Separator, Stack } from '@viraui/react';

const [value, setValue] = useState(['product', 'security']);

<Field.Root name="email-alerts">
  <Fieldset
    label="Email alerts"
    description="Pick every channel this workspace may email."
    render={<CheckboxGroup value={value} onValueChange={setValue} />}
  >
    <Stack rowGap="m">
      <Separator />
      <Checkbox
        label="Product updates"
        description="New features and changelog notes."
        value="product"
      />
      <Checkbox
        label="Security alerts"
        description="Login attempts and device trust."
        value="security"
      />
      <Checkbox
        label="Marketing"
        description="Occasional tips and webinars."
        value="marketing"
      />
    </Stack>
  </Fieldset>
</Field.Root>
```

</Example>

### Standalone checkbox

Standalone booleans under other fields wrap in their own `Field.Root` — no Fieldset without a shared legend.

<Example preview={<CheckboxFormFooterDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Checkbox, Stack, Textfield } from '@viraui/react';

<Stack rowGap="l">
  <Textfield label="Street address" required />
  <Textfield label="Apt / Suite" />
  <Field.Root name="save-as-default">
    <Checkbox label="Save as default address" defaultChecked />
  </Field.Root>
</Stack>
```

</Example>

### Surface card

`hPadding` / `vPadding` let the control fill a bordered `Surface`. Drive `Surface` `color` from checked state when the whole card should read as selected.

<Example preview={<CheckboxSurfaceCardDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Checkbox, Surface } from '@viraui/react';

const [checked, setChecked] = useState(false);

<Field.Root name="terms">
  <Surface border="all" radius="m" {...(checked ? { color: 3 } : {})}>
    <Checkbox
      checked={checked}
      onCheckedChange={setChecked}
      hPadding="m"
      vPadding="m"
      label="Accept terms of service"
      description="Required before payouts leave this workspace."
    />
  </Surface>
</Field.Root>
```

</Example>

### Select all

Lists of independent options stay one `Field.Root` + `Checkbox` per row. Drive a select-all row with Base UI `indeterminate` when some — but not all — children are checked.

<Example preview={<CheckboxSelectAllDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Checkbox, Separator, Stack, Surface, Text, Title } from '@viraui/react';

const keys = ['transaction', 'security', 'milestones', 'market'];
const [selected, setSelected] = useState(['transaction', 'security']);
const allChecked = selected.length === keys.length;
const someChecked = selected.length > 0 && !allChecked;

<Surface border="all" overflow="hidden" radius="l">
  <Stack hPadding="l" rowGap="m" vPadding="l">
    <Title />
    <Text />
    <Separator />
    <Field.Root name="select-all">
      <Checkbox
        label="Select all"
        checked={allChecked}
        indeterminate={someChecked}
        onCheckedChange={(next) => setSelected(next ? keys : [])}
      />
    </Field.Root>
    <Field.Root name="transaction">
      <Checkbox
        label="Transaction alerts"
        description="Deposits, withdrawals, and transfers."
        checked={selected.includes('transaction')}
        onCheckedChange={(next) => {
          setSelected((current) =>
            next
              ? [...current, 'transaction']
              : current.filter((item) => item !== 'transaction'),
          );
        }}
      />
    </Field.Root>
    {/* more Field.Root + Checkbox rows */}
  </Stack>
</Surface>
```

</Example>
