Textfield is the single-line text control for collecting a value. It mounts label, description, and error copy in the shared field layout, and optional `startAddon` / `endAddon` slots sit beside the control without becoming second fields.

Value, placeholder, disabled state, and validation pass through Base UI `Field` and `Input`, so you declare the whole row in JSX instead of hand-wiring labelled-by and error regions. Use `fullWidth` to span a form column (prefer that over inventing `width: 100%` CSS). `fitContent` grows the control inline with its value while block height stays fixed.

---

## When to use

- Single-line identifiers and short values (email, amount, search, city)
- Fields that need label, helper, or validation beside a native input
- Prefix, glyph, or small action chrome via start/end addons
- Native `date`, `time`, or `datetime-local` when the browser picker is enough

## When not to use

- The value spans multiple lines → [Textarea](/components/inputs/textarea)
- A closed list of named options in a popup → [Select](/components/inputs/select)
- Type-to-filter or free-form suggestions → [Autocomplete](/components/inputs/autocomplete)

## Common examples

### Labeled field

A labeled email with helper copy and Field validation is the baseline single-line input. Pair it with a submit button in a `Stack`; Textarea-style multi-line bodies belong on [`Textarea`](/components/inputs/textarea).

<Example preview={<TextfieldEmailDemo />}>

```tsx
import { Button, Stack, Textfield } from '@viraui/react';

<Stack rowGap="l">
  <Textfield
    type="email"
    autoComplete="email"
    fullWidth
    label="Email"
    description="We will send a magic link — no password required."
    name="email"
    placeholder="your@email.com"
    validationMode="onChange"
    validate={(value) => {
      const trimmed = String(value ?? '').trim();
      if (!trimmed) return 'Enter an email address.';
      if (!trimmed.includes('@')) return 'Enter a valid email address.';
      return null;
    }}
  />
  <Button />
</Stack>
```

</Example>

### Addons

`startAddon` and `endAddon` decorate the shared control group — prefix text, a search glyph, or a small action. Buttons inside addons must use `type="button"` and typically `size="s"` so they do not submit parent forms.

<Example preview={<TextfieldAddonsDemo />}>

```tsx
import { MagnifyingGlass } from '@phosphor-icons/react';
import { Button, Stack, Textfield } from '@viraui/react';

<Stack rowGap="m">
  <Textfield
    type="search"
    aria-label="Search holdings or tickers"
    fullWidth
    placeholder="Search holdings or tickers…"
    startAddon={<MagnifyingGlass aria-hidden size={16} />}
  />
  <Textfield
    fullWidth
    label="Amount to invest"
    defaultValue="1,000.00"
    startAddon={<>$</>}
  />
  <Textfield
    fullWidth
    label="Account holder"
    defaultValue="Synthetic Horizons Music LLC"
    endAddon={
      <Button size="s" variant="secondary" type="button" aria-label="Verify">
        Verify
      </Button>
    }
  />
</Stack>
```

</Example>

### Form row

Equal-width city / ZIP pairs share a parent `Stack` with `direction="row"` and `expandChildren` — do not invent width CSS on each field. Stack full-width fields above the row for street and suite.

<Example preview={<TextfieldAddressDemo />}>

```tsx
import { Stack, Textfield } from '@viraui/react';

<Stack rowGap="m">
  <Textfield fullWidth label="Street address" required defaultValue="123 Main Street" />
  <Textfield fullWidth label="Apt / Suite" defaultValue="Apt 4B" />
  <Stack columnGap="m" direction="row" expandChildren>
    <Textfield label="City" defaultValue="San Francisco" />
    <Textfield label="ZIP Code" defaultValue="94102" />
  </Stack>
</Stack>
```

</Example>

### Date and time

Pass native `type` values that ship pickers in Chrome, Safari, and Firefox — `date`, `time`, and `datetime-local`. Skip `month` and `week`; those fall back to plain text in Safari and Firefox. Values use the browser’s ISO forms (`YYYY-MM-DD`, `HH:MM`, `YYYY-MM-DDTHH:MM`).

<Example preview={<TextfieldDateTimeDemo />}>

```tsx
import { Stack, Textfield } from '@viraui/react';

<Stack rowGap="m">
  <Stack columnGap="m" direction="row" expandChildren>
    <Textfield type="date" label="Date" name="date" defaultValue="2026-10-05" />
    <Textfield type="time" label="Time" name="time" defaultValue="09:30" />
  </Stack>
  <Textfield
    type="datetime-local"
    fullWidth
    label="Date and time"
    name="datetime-local"
    defaultValue="2026-10-05T09:30"
  />
</Stack>
```

</Example>

### Fit content

`fitContent` sets `field-sizing: content` so the control grows inline with its value. Pair with `readOnly` and an `endAddon` copy action for share codes and clone URLs.

<Example preview={<TextfieldFitContentDemo />}>

```tsx
import { CopySimple } from '@phosphor-icons/react';
import { IconButton, Textfield } from '@viraui/react';

<Textfield
  fitContent
  readOnly
  aria-label="Preset share code"
  value="vira-preset-abc123"
  endAddon={
    <IconButton
      aria-label="Copy preset code"
      icon={<CopySimple />}
      size="s"
      variant="flat"
      type="button"
    />
  }
/>
```

</Example>
