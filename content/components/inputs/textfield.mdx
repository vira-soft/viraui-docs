`Textfield` wraps a native input in Vira's shared field layout — label, description, and error copy render through the same `FieldLabel` and `FieldHelperCopy` pattern as other inputs, and optional `startAddon` / `endAddon` slots sit beside the control without becoming second fields. Value, placeholder, disabled state, and validation pass through Base UI `Field` and `Input`; you declare the whole row in JSX instead of hand-wiring `aria-labelledby` and error regions. Use addons for prefix text or trailing icon buttons — buttons inside `endAddon` must use `type="button"` so they do not submit parent forms.
