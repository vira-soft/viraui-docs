Radio is one row in a mutually exclusive set. Each option carries its own label and optional description; `name`, validation, and group-level errors belong on an external `Field.Root` and [Fieldset](/components/inputs/fieldset), not on individual radios.

Always nest options inside `RadioGroup` so Base UI keeps keyboard roving and selection in sync. Add Fieldset with `render={<RadioGroup />}` only when the group needs a shared legend or helper copy; otherwise `RadioGroup` may sit directly in `Field.Root`.

---

## When to use

- Exactly one choice from a short, visible list (plan, contact channel, payout method)
- Options that benefit from a one-line description beside each control

## When not to use

- Several options can stay on at once → [Checkbox](/components/inputs/checkbox)
- The list is long, grouped in a popup, or needs a closed trigger → [Select](/components/inputs/select)
- Type-to-filter or free-form text → [Autocomplete](/components/inputs/autocomplete)

## Common examples

### Labeled group

A Fieldset-backed `RadioGroup` with labeled rows is the default single-choice pattern. Each option keeps its own `label` / `description`; the group owns `value` and `onValueChange`.

<Example preview={<RadioPlansDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Fieldset, Radio, RadioGroup, Separator, Stack } from '@viraui/react';

const [value, setValue] = useState('starter');

<Field.Root name="plan">
  <Fieldset
    label="Plan"
    description="Choose one plan for this workspace."
    render={<RadioGroup value={value} onValueChange={setValue} />}
  >
    <Stack rowGap="m">
      <Separator />
      <Radio
        label="Starter"
        description="Solo workspaces and early experiments."
        value="starter"
      />
      <Radio
        label="Pro"
        description="Shared seats, roles, and priority support."
        value="pro"
      />
      <Radio
        label="Enterprise"
        description="SSO, audit logs, and custom limits."
        value="enterprise"
      />
    </Stack>
  </Fieldset>
</Field.Root>
```

</Example>

### Without Fieldset

When every option already has a visible label and the group needs no shared legend, put `RadioGroup` directly under `Field.Root`.

<Example preview={<RadioContactDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Radio, RadioGroup, Stack } from '@viraui/react';

const [value, setValue] = useState('email');

<Field.Root name="preferred-contact">
  <RadioGroup value={value} onValueChange={setValue}>
    <Stack rowGap="m">
      <Radio
        label="Email"
        description="Daily digest to your inbox."
        value="email"
      />
      <Radio
        label="SMS"
        description="Urgent alerts to your phone."
        value="sms"
      />
      <Radio
        label="Push"
        description="In-app and device notifications."
        value="push"
      />
    </Stack>
  </RadioGroup>
</Field.Root>
```

</Example>

### Surface cards

`hPadding` / `vPadding` let each control fill a bordered `Surface`. Keep a resting `color` on every card and raise it when selected — toggling `color` on/off changes fill and can read as a layout jump. Equal columns use [`Grid`](/components/layout/grid) `columns={2}`, not a row `Stack` with uneven content widths.

<Example preview={<RadioSurfaceCardsDemo />}>

```tsx
import { Field } from '@base-ui/react';
import { Fieldset, Grid, Radio, RadioGroup, Surface } from '@viraui/react';

const [value, setValue] = useState('bank');

<Field.Root name="receiving-method">
  <Fieldset
    label="Receiving method"
    render={<RadioGroup value={value} onValueChange={setValue} />}
  >
    <Grid columnGap="m" columns={2}>
      <Surface
        border="all"
        color={value === 'bank' ? 3 : 1}
        radius="m"
      >
        <Radio
          label="Bank transfer"
          description="SWIFT / IBAN."
          value="bank"
          hPadding="m"
          vPadding="m"
        />
      </Surface>
      <Surface
        border="all"
        color={value === 'paypal' ? 3 : 1}
        radius="m"
      >
        <Radio
          label="PayPal"
          description="Instant payout."
          value="paypal"
          hPadding="m"
          vPadding="m"
        />
      </Surface>
    </Grid>
  </Fieldset>
</Field.Root>
```

</Example>
