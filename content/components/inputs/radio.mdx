---
title: Radio
description: Single-choice option row for use inside RadioGroup and Fieldset.
---

`Radio` is one row in a mutually exclusive set — each option carries its own label and optional description, while `name`, validation, and group-level errors belong on an external `Field.Root` and [`Fieldset`](/components/inputs/fieldset), not on individual radios. Options render inside `RadioGroup` so Base UI keeps keyboard roving and selection in sync. Use `Radio` when exactly one choice is allowed; use [`Checkbox`](/components/inputs/checkbox) when multiple independent toggles fit the task, and [`Select`](/components/inputs/select) when the option list is long or needs grouping in a popup.
