title: Switch
description: Toggle control for immediate on/off settings with label and helper copy.
---

`Switch` maps a boolean setting to a sliding toggle — checked state, disabled, and change handlers pass through Base UI `Switch`, while label, description, and error copy use the same field row layout as `Checkbox` and `Radio`. Prefer `Switch` when the change applies immediately (feature flags, dark mode, notification mute) rather than on form submit; use `Checkbox` when the value is part of a larger form batch or when multiple independent options can be on at once. Wrap in `Field.Root` when validation or naming is required.
