Inputs in ViraUI are the controls that collect typed values — text, choices, ranges, and combobox queries — each wrapped in shared field chrome so label, helper copy, and error regions stay wired without hand-built aria trees. Most inputs lean on Base UI `Field` for validation and naming; groups of radios and checkboxes pair with [`Fieldset`](/components/inputs/fieldset) so legends and group-level errors read as one unit. Paste compose prompts into your agent and let `viraui-design` read `@viraui/react` specs before it ships markup.
