## How it works

`DirectionProvider` and `useDirection` are a transparent re-export of Base UI’s direction utilities. They feed Base UI context so wrapped controls flip for RTL; they do **not** set HTML `dir` or CSS `direction`. Pair the provider with `dir="rtl"` on a portal ancestor — usually `<html>` — so body-mounted popups inherit the same direction.

Optional beyond [Setup](/get-started/setup). Import from `@viraui/react` instead of `@base-ui/react/direction-provider`. Full API stays on [Base UI](https://base-ui.com/react/utils/direction-provider).

## Common examples

### RTL subtree with Slider

```tsx
import { DirectionProvider, Slider } from '@viraui/react';

<div dir="rtl">
  <DirectionProvider direction="rtl">
    <Slider defaultValue={25} aria-label="Volume" />
  </DirectionProvider>
</div>
```

### Read direction in a portal-safe hook

```tsx
import { DirectionProvider, Text, useDirection } from '@viraui/react';

function DirectionLabel() {
  const direction = useDirection();
  return <Text size="s">Direction: {direction}</Text>;
}

<DirectionProvider direction="rtl">
  <DirectionLabel />
</DirectionProvider>
```
