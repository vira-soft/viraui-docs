The ViraUI docs MCP exposes this site to your coding agent over Streamable HTTP. Connect the client to `https://docs.viraui.dev/mcp` (no auth). From chat, the agent can search and open published pages instead of guessing from training data.

Available tools:

- `search`: full-text queries with snippets
- `get_page`: load one page by path (such as `/principles` or `/get-started/setup`)
- `list_pages`: map the index before opening detail

MCP does not replace the agent instructions shipped with the design system. This site explains how each part works and gives copy-ready prompts; technical contracts live in the packages ([skills](/get-started/skills) playbooks and live specs in `@viraui/react`).

Use MCP when the agent needs a grounded lookup or check against what is published here. Use skills when it should edit the app.

For any MCP-capable client, paste this:

```markdown tab="Configure MCP"
Add the ViraUI docs MCP to this client as viraui-docs. Use Streamable HTTP at https://docs.viraui.dev/mcp — no auth. Prefer the client's native MCP config or CLI (merge into existing servers; do not wipe other entries). Confirm the server connects and that search, get_page, and list_pages are available.
```

## Check connection

After the server shows as connected, run one of these checks to confirm the tools respond:

```text tab="Search docs"
Search the ViraUI docs for Stack layout guidance and summarize the first few hits with links.
```
```text tab="Fetch a page"
Open the Principles page from the docs and quote the three principles in order.
```
```text tab="Browse the index"
Browse the docs index, then open the Get started and Foundation pages most helpful for setting up a new app.
```
